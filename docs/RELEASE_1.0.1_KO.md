# 1.0.1 — Make Shotguns Great Again! 1.17.0 대응

SPT 4.1.6용 SPT Mod Korean Addon 1.0.1 데이터 업데이트입니다.

## 변경 내용

- `Make Shotguns Great Again!` 1.17.0 기준 신규 로케일 68행을 추가했습니다.
  - 신규 아이템 11종 관련 33행
  - 추가 프리셋/로케일 3행
  - 신규 퀘스트 6개 관련 32행
- 기존 MSGA 로케일 69행은 1.17.0 원문과 일치하여 유지했습니다.
- F12 설정의 `KS-23 Mount Calibration > Enable Mount Alignment Fix` 설명 원문 변경 1건을 반영했습니다.
- 클라이언트/서버 애드온 버전을 1.0.1로 올렸습니다.

코드 동작 규격 자체는 1.0.0과 동일하며, 이번 릴리스의 핵심은 번역 데이터 갱신입니다.
