# 모드 번역 대상·진행 인계 기록 — 작성 양식

이 파일은 **작업 중인 모드별로 별도 작성하는 인계 기록의 양식**이다. 현재 저장소의 `docs/`에 포함된 공통 양식이며 배포용 파일이 아니다. 실제 작성한 인계·검증 기록은 `docs/records/work-history/`에 저장한다. `docs/` 최상위에 이 공통 양식을 두고, 작업별 실제 기록은 `docs/records/`에서만 관리한다. 인계 기록은 분석과 번역의 누락을 방지하기 위한 작업 자료이며, 사용자용 설치 ZIP에 포함하지 않는다.

## 응답 게이트 재확인 (매 답변의 필수 조건)

프로젝트의 응답 전 필수 문서·순서는 `docs/AGENTS.md`의 단일 목록을 따라 실제로 다시 읽는다. **인계 기록의 앞선 검증 완료 표기는 새 게임 증거 앞에서 우선하지 않는다.** 이 양식은 실제 작업 기록을 남기는 용도이며, 문서를 읽지 않은 채 형식만 채워 `검증`이라고 주장해서는 안 된다.

## A. 이번 작업의 기준

- 사용자 요청/제외 대상:
- 애드온 소스 파일명/버전·해시(확인할 수 있는 경우):
- 원본 모드명·GUID·버전·원본 ZIP/파일:
- **번역 기준 소스 버전 / 공식 사이트 조회 버전 / 실제 번역·게임 검증 버전(각각 구분):**
- **버전 근거(원본 ZIP/주 프로젝트/공식 URL·조회일) 및 확인 불가 사유:**
- **관련 일반 번역/F12 프로필 경로와 `mod_version` 기록 상태:**
- **버전 관리 대장·근거 CSV 갱신 여부(기존 값 변경 시 사유 포함):**
- 이전 턴에서 확인한 조사/누적 번역 파일:
- **이번 응답에서 실제 다시 연 문서와 경로:** `docs/AGENTS.md`, `모드번역_작업절차.md`, `응답전_필수확인.md`, 관련 포맷/Prompt/원본/프로필 (미열람한 문서는 기재 금지)
- 읽은 지침: `모드번역_작업절차.md`, `번역작업안내서.md`, `TRANSLATION_FORMAT.md`, `prompts/translate_prompt.txt`
- 이번 요청 종류: `분석 / 번역 / 분할 / 소스파일 / 배포용 빌드 / 업데이트 노트`

## B. 번역 대상 대조표

| ID | 모드·버전 | 원본 파일/키 또는 타입·메서드 | 표시 화면/화자 | 원문/수량 | 기존 번역·원문 일치 | 적용 채널·훅 | 상태·근거 |
|---|---|---|---|---|---|---|---|
| 예시-1 | Example 1.0 | `PluginConfig.cs:Config.Bind(...)` | F12 설정 | 설정명 + 설명 + 분류 | 미등록 | `config-ui/<GUID>.json` | 조사 완료 / 구현 전 |
| 예시-2 | Example 1.0 | `Gui.Draw()` | 독립 UI 버튼 | `Apply` | 없음 | 특정 출력 메서드 애드온 훅 필요 | 조사 완료 / 구현 전 |

위 예시는 **작성 방법을 설명하는 가상 데이터**다. 실제 기록에는 원본에서 확인한 ID·키·코드 위치만 적는다. 대량 로케일은 상세 JSON/CSV 목록을 별도 작업 자료로 두되, 요약표의 키 수와 누적 결과 파일을 연결한다.

**상태 기록 기준:** `조사 완료` / `번역 작성` / `로더·훅 연결 확인` / `정적 검사 통과` / `빌드 통과` / `인게임 확인` / `비대상(사유)` / `원문 유지(사유)` / `보류(이유)` / `미완료`. 한 단계가 통과했다고 그다음 단계까지 통과한 것으로 표시하지 않는다.

### B-1. 동일 키의 공급원·최종 로케일 추적표 (필수)

동일 로케일 키에 영어를 공급하는 경로가 둘 이상이면 **공급원별 별도 행**으로 기록한다. 실제 사용하지 않는 내부 문자열은 분류·사유를 남긴다.

| 모드·현재 버전 | 키/표시 대상 | 원본 파일·코드 메서드 | 공급 영어/언어·실행 조건 | 선행·후처리·덮어쓰기 순서 | 코드상 예상 최종 영어 | 실제 서버/게임 영어·증거 | 번역 `source`·상속 `match_mode` | 로더/훅·선택 결과 | 판정 |
|---|---|---|---|---|---|---|---|---|---|
| 예시 | `trader Description` | `AddTraderToLocales` | 서버 등록 영어 / kr | 뒤이어 fallback, 기존 값 보존 | 정적 추론값 | `미확인`(스냅샷 없음) | 기본 프로필 source / exact | 후보 일치 검증 필요 | `런타임 미확인` |

**증거 분류:** `원본 코드 확인`, `정적 예상값`, `실제 서버 스냅샷 확인`, `실게임 표시 확인`은 서로 다른 상태다. 코드만 읽었을 때 실제 출력이 검증됐다고 적지 않는다. 별도 후보 목록의 전체 N건에 대해 `정상/수정/미번역/미연결/비대상/보류/미확인`을 집계하고, 증거 파일 경로·수집 버전을 기록한다.

## C. 빠뜨리기 쉬운 경로 확인

- [ ] 아이템·의류·퀘스트 전체 메시지/목표·상인·업적·읽는 문서 등 글로벌 로케일
- [ ] F12 설정의 **이름/설명/분류/표시 선택값**과 조건부·사용자 지정 UI
- [ ] TMP/Text, GUI/GUILayout, 버튼, 알림, 팝업, 툴팁, 편집기, 사망 화면
- [ ] 배열·Dictionary·캐시·문자열 조립·언어 변경 시 다시 표시되는 경로
- [ ] 직접 NPC/USER/SYSTEM 메일, 서버 오류, 자체 다국어 로더, 웹 UI
- [ ] DLL 전용 모드의 확인 가능한 문자열과 미확인 출력 지점 구분
- [ ] 기존 프로필과 최신 원문 불일치, 버전 검사, 호출자 범위
- [ ] 동일 키의 서버 등록·JSON·transformer·언어별 fallback·캐시 공급원 및 실제 호출/덮어쓰기 순서
- [ ] 코드상 예상 최종값과 실제 서버/화면 원문을 구분, 상속 `match_mode`와 첫 선택 후보·미연결 경로 확인
- [ ] 최신 버전 전용 회귀 대조(정상 한국어 보존, 구버전 전용 원문·호환 파일 복원 금지)
- [ ] 비대상 로그·내부 이름·숨김 값·저장 키 구분

## F. 최종 문서 갱신 기록 — 필수

작업별 실제 인계 기록을 작성할 때 이 절을 채운다. 공통 양식 파일을 매번 변경할 필요는 없지만 **실제 번역·코드 작업이 끝나면** 이 표를 점검한다.

| 문서/위치 | 갱신 여부·변경 내용 또는 변경 없음 사유 |
|---|---|
| `docs/번역작업안내서.md` 및 번역 규칙·Prompt | |
| `docs/records/work-history/` 작업별 번역 대상·완료/미완료·훅 연결 인계 기록 | |
| `docs/records/versioning/번역_원본모드_버전관리대장_20261023.md` / `docs/records/versioning/번역_원본모드_버전_근거목록_20261023.csv` (번역·F12 작업 시 원본 버전 근거 동기화) | |
| `note/README.md` (설치·필수 모드·버전) | |
| `note/번역지원모드목록.md` (신규·변경 지원 범위) | |
| `note/update.md` (마지막 공개본 대비 최종 변경점만; 같은 버전 내부 수정 내역은 제외, 변경 없으면 미수정) | |
| 실제 프로젝트 버전·배포 스크립트/목록 출력 경로 대조 | |
| 공개 안내·지원 모드 목록·실제 배포물 교차 확인 | |

문서 갱신이 필요한데 누락된 상태라면 결과를 최종 완료로 판정하지 않는다. 작업 기록은 다음 턴으로 미루지 않되, 공개 버전 간 변경점이 없는 `note/update.md`는 수정하지 않는다. 공개 노트를 작업 일지로 사용하지 않는다.
