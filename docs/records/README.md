# 작업·수정 기록 보관소 (현행 지침 아님)

이 폴더는 **작업 기록과 증거**만 보관합니다. `docs/`의 현행 작업 지시·매뉴얼과 구분합니다.

- `work-history/`: 이전 버전 릴리스·재검토·회귀·화자 검수 등 작업별 인계와 수정 결과
- `audits/`: 과거 코드·성능 분석, 퀘스트 감사 CSV 등 조사 결과
- `versioning/`: 원본 모드 버전 관리 대장 및 버전 근거 CSV
- `patches/`: 이전 `docs/patches/`의 과거 감사·인계 파일 원본. **내용을 읽거나 수정하지 않고 위치만 옮겨 보존**

새 작업의 중간/최종 수정 기록은 이 아래에 작성합니다. 예전 기록에 존재하는 `docs/` 경로는 작성 당시의 이력이며 현재 경로가 아닐 수 있습니다. 현재 작업 규칙은 `AGENTS.md` 및 `docs/`의 현행 매뉴얼이 기준입니다.
