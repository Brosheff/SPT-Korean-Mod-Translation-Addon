# ArenaMode 0.1.1 UI 출력 후보 소스 역대조

원본 `ArenaMode.Client`의 직접 TMP/Text·툴팁·IMGUI 호출을 검색한 **정적 후보 목록**. 모든 429개 파일을 검색했으며,
검사된 직접 호출 후보는 **111곳**입니다. 호출이 화면에 표시된다는 사실이나 훅의 실행 성공을 뜻하지 않습니다.
내부 객체 이름·로그·간접 렌더링 등은 별도로 판정해야 하며, `미확인`은 완료가 아닙니다.

**추가로 확인한 원본 IMGUI 출력 8곳** (아래 111곳 외): `Hud/ArenaPanel.cs`의 `GUI.Window` (230행), `Hud/TacticalBuyPanel.cs`의 `GUI.Window` (238행), `Hud/ArenaPanel.cs`의 `GUILayout.Toggle` (289, 291, 293, 295, 297, 299행). 제목과 설정 레이블은 모두 기존 ArenaMode 프로필의 실제 번역문을 사용하며, 모드 내부 선택값을 건드리지 않습니다. 정적 후보 합계 **119곳**; 실제 런타임 적용은 미검증입니다.
