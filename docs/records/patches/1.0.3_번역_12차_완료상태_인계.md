# 1.0.3 번역 완료·원문 유지 상태표 — 12차 (기록 정리)

> **기준:** `SPT-Korean-Addon-1.0.3-Development-Batch11-Source.zip` 및 `SPT-Korean-Addon-1.0.3-Batch11-Inventory-Handoff.zip`의 후보 ID 2,099개. 기존 번역 데이터를 새로 번역하거나 상태만으로 게임 적용을 주장하지 않는다. 프로젝트 표시 버전은 1.0.2 유지.

## 1. 상태 명칭과 집계

| 기록용 상태 | 기존 인계 상태값 | 개수 | 의미 |
|---|---|---:|---|
| **번역 작성 완료** | `translated` | 1,755 | 번역 본문 또는 소스 훅이 있고 지정 증거가 확인된 항목. *빌드/인게임 확인과 다름* |
| **표기 검토 완료(원문 유지)** | `source_kept` | 255 | 모델명·고유 약어·기존 확정 표기라 의도적으로 원문 유지. 한국어 번역했다고 기록하지 않음 |

| **조사 후보 합계** |  | 2,099 | 작업 후보만을 대상으로 함. 애드온의 기존 전체 지원 항목 수와 다름 |

**데이터상 번역·표기 결정 완료: 2,010개.** 이 수는 `번역 본문·훅 등 작성 완료 항목 1,755개`와 `원문 유지 255개`를 합친 결정 완료 수치다. '전체 완역' 또는 '실제 인게임 작동'이라는 의미가 아니다.

| 모드 | 번역 작성 완료 | 원문 유지 | 비대상 | 보류 |

- Rook 및 Russian Special Forces Pack은 이번 패치에서 조사된 누락 항목의 데이터 작성과 원문 대조를 완료했다.

- True North의 `source_kept` 단축명 92개는 제품 코드/약어를 지침에 따라 그대로 둔 것이며 누락이 아니다. `non_target` 81개는 빈 원문이다.
- Epic's All in One은 조사된 원본 1,547개 중 1,385개가 번역 상태, 162개가 모델명/약어 원문 유지다. 기존 프로필에 보존된 레거시 118개는 이번 원본에 없는 키라 이 집계에 별도로 추가하지 않는다.

## 5. 이번 정리에서 파일 처리와 후처리

- 번역 JSON, C# 훅, `handoff.json`, `candidate_inventory.json`은 **변경하지 않는다**. 이미 정해진 `translated`/`source_kept`/`non_target`/`blocked` 구분이 근거에 부합한다.
- 이 문서는 한국어 상태표를 추가하는 기록 정리 작업이다. 상태값을 더 좋게 보이도록 고치지 않는다.
- `note/번역지원모드목록.md`: 지원 모드·채널 추가/삭제 없음. 기존 자동생성 목록을 그대로 유지한다.
- `note/README.md`, `note/update.md`: 정식 1.0.3 배포 전이며 설치/버전 변경 없음. 수정하지 않는다.
- 문서 작성 후 `tools/verify_workflow.py source/documents/handoff`와 회귀 테스트를 실행해 결과를 별도 인계 파일에 기록한다.
- 기존 파일 삭제 없음. **배포용 빌드가 아닌 수정 소스와 작업 기록**이다.
