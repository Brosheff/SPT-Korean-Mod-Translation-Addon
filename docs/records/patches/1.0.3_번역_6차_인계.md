# 1.0.3 번역 작업 인계 — 6차 (2026-10-15)

> **개발 중간 소스입니다.** 1.0.2 프로젝트 버전 유지. JSON 작성·애드온 C# 훅 연결 및 정적 검증을 완료했으나, C# 빌드/설치 ZIP/게임 내 표시 검증은 **미실시**입니다. **코드 연결이 곧 작동 확인은 아닙니다.**

## A. 기준·요청 범위·원본

- 5차 전체 누적 소스(`SPT-Korean-Addon-1.0.3-Development-Batch5-Source.zip`) 및 5차 후보/인계 기록을 보존합니다. 이번 회차는 **ISB Special Forces 2.0.0 원본의 자막·알림 직접 출력**만 처리합니다. ISB Aishi 결과 화면, Under Fire 효과명, 기타 모드 번역은 보류했습니다.
- 원본: 업로드된 `ISB-Special-Forces-2.0.0.zip`의 `ISBSOFExtras/SubtitleSystem.cs`, `ISBSOFExtras/ISBSpecialForces_Audios/Subtitles/{locales/en.json,cues.json}`, `ISBNotify/ISBNotify.cs`, `ISBNotify/ISBNotify.csproj`.
- 사용자 최상위 지침: `docs/모드번역_작업절차.md` → `번역작업안내서.md` → `TRANSLATION_FORMAT.md` → `prompts/translate_prompt.txt` → 인계 양식 → `tools/VERIFY_WORKFLOW.md` 재검토.
- 원본 `ISBNotify` C# 어셈블리명은 프로젝트에서 `ISBNotify`, 자막 어셈블리명은 `ISBSOF_Extras`, 자막 메서드의 실제 선언 타입은 `ISBSSOFExtra.ISBSubtitleSystem`임을 확인. 압축 파일명 2.0.0과 내부 버전/SPT 호환 선언의 이전 차이는 4차 기록대로 미해결입니다.

## C. 누적 후보·잔여 미완료 및 검증

- 동반 인계 자료 `candidate_inventory.json`, `handoff.json`, `batch6_new_rows.json`, `batch6_summary.json`에 개별 키·검증 상태·후처리 로그를 기록합니다. 5차의 누적 549개 후보에 `sf:subtitle:ResolveText-hook` 연결 후보 1개를 더했습니다. `handoff` 검사는 정적 근거만 확인하며 실행을 보증하지 않습니다.
- **미완료/보류:** Under Fire 건강 효과 `Adrenaline` 표시, ISB Aishi 레이드 결과 독립 UI 및 bare ID 두 개의 조건 연결. 기존 True North 원본 밖 74개는 삭제하지 않고 유지합니다.
- **실행 단계 구분:** JSON/원문/태그 대조 `통과`; 애드온 정적 소스 검사 `통과`; 기존 워크플로 회귀 검사 `통과`; **C# 컴파일 `미실시`**, 배포 패키지 `미제작`, SPT 4.1.6 설치 후 화면 `미확인`.
- **안전한 실패:** 영어 이외의 자막, 알 수 없는 본문, 비한국어 언어, 대상 모드/메서드가 없을 때는 소스에서 번역하지 않도록 조건을 지정했습니다. 실제 변경/지연 로딩 충돌·게임 안정성은 런타임 검증이 필요합니다.
