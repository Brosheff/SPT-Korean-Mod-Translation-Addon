# 1.0.3 번역 작업 인계 — 4차 (2026-10-15)

> 배포용 문서가 아닌 개발 인계 기록입니다. 이번 회차는 **번역 JSON/F12 데이터 작성 및 정적 검사** 단계이며, 프로젝트 버전은 아직 1.0.2입니다. 모드 소스의 빌드 및 인게임 표시 결과를 의미하지 않습니다.

## A. 기준·원본·적용 범위

- **기준 누적 소스:** `SPT-Korean-Addon-1.0.3-Development-Batch3-Source.zip` 및 `docs/patches/1.0.3_번역_3차_인계.md`; 기존 `translations`, `config-ui`, 로더와 훅 보존.
- **원본 모드:** `ISB-Special-Forces-2.0.0.zip`, `ISB-Aishi-2.0.3.zip`, `True-North-4.0.29.zip`. 모두 업로드된 압축의 실제 JSON/C#을 재열람했습니다.
- **버전 주의:** ISB Special Forces 압축명은 2.0.0이지만 내부 `Server/Mod.cs`, `Plugin/PluginInfo.cs`에는 1.0.4, 서버 메타데이터의 SPT 범위는 `~4.0.13`으로 선언되어 있습니다. 이 자료만으로 4.1.6에서 정상 실행한다고 단정할 수 없습니다. 반대로 문서상의 버전 차이를 이유로 원본 모드를 수정하지도 않았습니다.
- **읽은 문서:** `docs/모드번역_작업절차.md`, `번역작업안내서.md` 0-1절, `TRANSLATION_FORMAT.md`, `prompts/translate_prompt.txt`, `번역대상_인계기록_양식.md`, `tools/VERIFY_WORKFLOW.md`. 원본 원문과 사용자 지정 명칭·아이템 단축명 표기를 우선했습니다.
- **작업 분할:** 연결 확인이 쉬운 기본 `locale`/일반 F12부터 적용합니다. 새로운 UI 훅·자체 자막·직접 알림 및 True North 변경 퀘스트는 후속 회차로 분리합니다. 원본 모드 파일, 설치본 또는 별도 `extras` 패치는 제작하지 않았습니다.

- **신규 프로필:** `translations/ISB Special Forces.json`, `mod_id: com.samc137.isbspecialforces`, `mod_name: ISB Special Forces`. 다른 모드의 프로필 ID를 임의로 합치지 않았습니다.
- **ISB Aishi:** 원본 en 파일들의 합집합 1,005개와 기존 1,953행을 대조한 결과, 기존에 공통으로 존재한 키의 `source` 불일치는 **0**입니다. 누락 4개 중 3개를 추가(누적 1,956행)하고 원문이 빈 `startedMessageText` 1개는 비대상으로 기록했습니다. 기존에만 있던 데이터 952행은 삭제하지 않았습니다. 신규 bare ID 두 개의 조건 연결은 현재 제공된 퀘스트 정의에서 확인되지 않아 화면 표시 종류는 지정하지 않고 실제 사용은 미확인으로 남깁니다.
- **True North:** 원본 영어 로케일 합집합 2,064키를 기존 1,919행과 비교했습니다. 이번 회차의 단축명 127개 추가 후 누적 2,046행입니다. 새 원문에 없는 기존 행 74개는 삭제하지 않았습니다. **나머지 원본 누락 92개** 및 **기존 행과 원문이 바뀐 54개**는 번역을 임의로 덮어쓰지 않고 별도 인계 자료에 보존했습니다. 원문 불일치 54개는 현 버전에서 적용 실패 가능성이 있으므로 후속 수동 검토 대상입니다.
- **원문 보존:** 추가한 모든 `source`와 키를 원본 바이트의 JSON 디코딩 결과에 1:1 대응했습니다. 매 신규 행에 `match_mode: exact`를 명시하여 직전 행 설정값의 암묵적 상속을 막았습니다. 목적/제목/업적에는 코드가 자동 표시할 영문과 모드명을 사람이 중복 삽입하지 않았습니다.
- **F12:** `categories`, `entries`, GUID와 소스 description은 실제 C#을 참조합니다. `Config.Bind` 기본값, `Auto`, 영문 로케일 코드, enum, 설정의 저장 키/값은 변경하지 않았습니다. 자막 언어 설정의 한국어 번역은 **한국어 자막 지원 추가가 아닙니다**.
