# 1.0.3 — 프로젝트 버전 및 공개용 업데이트 노트 갱신 인계

## A. 기준과 요청

- 사용자의 요청: 직전 작업에서 제공한 ArenaMode 0.1.1 전체 UI 출력 경로 재감사 **누적 소스**를 기준으로 1.0.3 버전 지정 및 공개 업데이트 노트 갱신.
- 실제 기준 소스: `SPT-Korean-Addon-1.0.3-ArenaMode-0.1.1-Full-UI-Output-Reaudit-Source.zip`.
- 직전 공개본 판단 근거: 이 기준 소스에 포함된 `note/update.md`의 게시 제목 `SPT Mod Korean Addon v1.0.2`와 클라이언트·서버 런타임 버전 `1.0.2`. 실제 외부 게시 이력은 여기에서 직접 확인하지 못함.
- 확인한 필수 문서: `AGENTS.md`, `docs/모드번역_작업절차.md`, `docs/응답전_필수확인.md`, `docs/번역작업안내서.md`, `docs/TRANSLATION_FORMAT.md`, `docs/prompts/translate_prompt.txt`, `docs/배포_업데이트노트_작성지침.md`, `docs/번역대상_인계기록_양식.md`, `docs/DISTRIBUTION_LAYOUT.txt`.

## B. 버전 변경

1. `SPT_Mod_Korean_Addon.csproj`: 클라이언트 어셈블리 빌드 버전 `1.0.3`.
2. `src/Plugin.cs`: BepInEx 플러그인 버전 및 로드 로그 `1.0.3`.
3. `server-src/SPT_Mod_Korean_Server/SPT_Mod_Korean_Server.csproj`: 서버 어셈블리 빌드 버전 `1.0.3`.
4. `server-src/SPT_Mod_Korean_Server/Metadata.cs`: SPT 서버 모드 메타데이터 `1.0.3`.
5. `server-src/SPT_Mod_Korean_Server/Mod.cs`: 서버 로드 로그 `1.0.3`.
6. `note/README.md`: 사용자 공개 제목 `v1.0.3` 및 버전 종속 문장 정리.
7. `note/update.md`: 승인된 3개 섹션만 사용해 `v1.0.3` 공개 안내 갱신.
8. `note/번역지원모드목록.md`: 제공된 `tools/build_supported_mods.py`로 버전 헤더를 `1.0.3`에 맞춰 재생성.
9. `tests/WorkflowChecks/test_release_version_consistency.py`: 위 버전들의 정적 일치 검사 추가.

`BUILD_DISTRIBUTION.ps1`는 클라이언트 `.csproj`의 버전을 읽어 배포 파일명을 자동 생성하므로 빌드 스크립트 로직은 변경하지 않음. 일반 과거 기록의 `1.0.2`, 테스트용 이전 버전 문자열, 다른 모드의 버전 언급은 변경하지 않음.

## C. 사용자 공개 노트 검토

- 신규 지원: ArenaMode, Hood's More Energy Drinks, ISB Special Forces, Under Fire, Dynamic Item Weights. 기준 1.0.2 소스와 모드·설정 프로필 유무를 비교함.
- 기존 지원 개선: ECOTI 3.4.0, Rook, Russian Special Forces Pack, C11 - True North, ISB Aishi, Epic's All in One, 일부 중복 영문 병기 및 장탄수·명칭 교정.
- 출시 전 회차별 ArenaMode 재구현·컴파일 오류·번역 수정을 별개 공개 항목으로 나열하지 않음.
- ArenaMode의 정적 번역 규칙은 포함하지만 인게임 전수 검증이 없으므로 **일부 UI 번역**이라고만 표기하며, 전체 UI 100% 완역을 주장하지 않음.
- 설치 섹션은 기존 승인 양식과 필수 선행 모드 링크를 유지함.

## D. 검증과 미확인

| 단계 | 상태 |
|---|---|
| 소스 파일 변경·버전 상호 일치 | 정적 대조 수행 |
| 번역 JSON 및 F12/로더 정적 검사 | `python tools/validate_translations.py`, `python tools/verify_workflow.py source` |
| 문서 정적 검사 | `python tools/verify_workflow.py documents` |
| 회귀 테스트 | `python -m unittest discover -s tests/WorkflowChecks -p 'test_*.py' -q` |
| C# 클라이언트·서버 빌드 | **미실시** — 해당 작업 환경에 `dotnet` SDK 없음 |
| `_dist` 설치 ZIP 제작/검증 | **미실시** — 실제 빌드 DLL이 없으므로 소스 ZIP만 제공 |
| 인게임 ArenaMode UI·모드 로케일 전수 검증 | **미실시** — 이전 한글화 누락이 해결됐다고 단정하지 않음 |

## E. 문서 후처리

- 공개용 `note/update.md`, `note/README.md` 갱신, 지원 목록 재생성.
- 기존 번역 규격, Prompt, 모드별 JSON, C# 로더 구현, F12 데이터 및 빌드 스크립트는 변경하지 않음.
- `docs`에는 이번 버전 지정 및 검증 단계 인계만 추가. 다른 모드의 모드 ID/버전과 게임 로직 변경 없음.
- 결과물 종류: **전체 프로젝트 소스 ZIP**, 사용자 설치용 `dist` 아님.
