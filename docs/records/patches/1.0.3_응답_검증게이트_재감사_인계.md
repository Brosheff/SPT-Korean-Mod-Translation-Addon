# 1.0.3 응답 전 문서 게이트 및 재감사 인계

## 목적과 발견된 결함

- 사용자가 게임 내 VKS 12.7x55 ST-130 총구제퇴기의 **영어 이름·영어 설명**을 화면으로 제시함.
- 원본 ZIP과 기존 번역 JSON의 `source` 비교는 통과했으나, 화면의 실제 원문 표기가 다름(`VSK` 대 `VKS`). 따라서 **기존 1~13차 정적 검사만으로 인게임 적용을 보증할 수 없음**이 드러남.
- 이전 회차의 `번역 작성 완료`는 데이터 작성 상태로만 해석한다. 같은 경로의 전체 항목에 대한 `인게임 적용 완료` 선언은 보류한다.
- 대상 범위: 모든 1~13차 신규/수정 로케일, 원문 유지 항목 중 오해 가능 항목, 동일 로케일 키 후보 및 `match_mode` 상속 경계. **실제 전체 적용률/해결 건수는 미확인**.

## 이번 문서 변경

- `AGENTS.md`: 이 프로젝트에 관한 **매 응답마다** 문서를 다시 열고, 직접 데이터와 대조하도록 최상단 지침 추가.
- `docs/응답전_필수확인.md`: 질문 유형별 사전 확인·런타임 영어 원문 대조·같은 로더 범위 재감사·상태 구분을 단계화.
- `docs/모드번역_작업절차.md`: 0-A 응답 게이트와 작업 종료 체크 항목 추가.
- `docs/번역작업안내서.md`, `docs/TRANSLATION_FORMAT.md`: 아이템 원문 런타임 불일치와 적용 검증 주의 보강.
- `docs/번역대상_인계기록_양식.md`: 답변 시 재열람 경로 및 실제 런타임 대조 필드 추가.
- `tools/verify_workflow.py documents`: 문서 및 핵심 게이트가 누락되면 실패하도록 구조 검사 강화.
- `tests/WorkflowChecks/test_verify_workflow.py`: 누락된 응답 문서·삭제된 핵심 지시를 감지하는 회귀 테스트 3개 추가.
- `tools/VERIFY_WORKFLOW.md`: 응답 문서 검사 방법과 검사 한계 설명 추가.

## 후속 재감사 필수 범위 및 판정

1. 현재 누적 소스와 원본 모드/프로필의 모든 신규·수정 아이템 **Name / ShortName / Description** 대조.
2. 실제 게임의 locale 값이 확보된 항목은 key/source/선택 모드/원문/번역을 하나씩 대조. 없는 값은 미확인으로 유지.
3. 모드 사이의 동일 키 후보, 서로 다른 원문, 로더의 첫 번째 후보 우선 규칙, `match_mode` 상속을 재검사. 오류인지 정상 공존인지 구분.
4. 확인된 결함만 수정하고 JSON·정적 검사, 빌드, 실제 `dist` 설치 반영, 인게임 출력 단계를 분리해 기록.
5. 정적 검사 통과를 `모두 번역 적용됨`으로 서술하지 않는다.

**현재 완료된 것은 문서 게이트 정비이며, 전체 코드·번역 데이터 재감사 또는 인게임 재검증을 완료했다는 뜻이 아니다.** `note/update.md`는 미배포 개발 수정이므로 변경하지 않는다.
