# 1.0.3 작업용 번역 인계 — 2차 (2026-10-15)

> 이 문서는 **개발 중 인계 기록**이며 공개 업데이트 노트가 아닙니다. 1.0.3 목표 작업이 진행 중입니다. 실제 프로젝트 버전은 계속 1.0.2이며, 빌드·배포·인게임 적용을 완료했다고 뜻하지 않습니다.

## A. 이번 작업의 기준과 범위

- 사용자 요청: 7개 제공 모드의 번역 작업을 여러 회차로 나누어 누적 수행하고, 모든 후처리를 프로젝트 문서대로 수행.
- 직전 누적 기준: `SPT-Korean-Addon-1.0.3-Development-Batch1-Source.zip`의 1차 소스. `docs/patches/1.0.3_번역_1차_인계.md`와 그 후보 기록을 보존.
- 원본 1: `YDLonewolf-Rook-v.1.2.1.zip`, 실제 SPT 4.1.6 대상 원본은 `SPT-4.1.6/db/CustomLocales/en.json`. **주의: 압축파일명은 1.2.1이지만 해당 소스의 `SPT-4.1.6/ModMetadata.cs`에 선언된 버전은 1.2.0**입니다. 설치 DLL의 실제 버전은 확인하지 못했으므로 이 차이를 기록하고 어느 쪽도 실제 설치 버전으로 단정하지 않음.
- 원본 2: `Russian-SF-Pack-2.0.1.zip`, `RussianSFPack/Resources/db/CustomItems/**/*.json`의 `locales.en` 15개 데이터 파일(현재 로케일 총 327키). 실제 모드 GUID `com.wtt.russiansfpack`, WTT CommonLib의 사용자 지정 아이템 생성 호출을 확인.
- 번역 규칙: `docs/모드번역_작업절차.md` → `docs/번역작업안내서.md` → `docs/TRANSLATION_FORMAT.md` → `docs/prompts/translate_prompt.txt` → 인계기록 양식을 다시 확인. 문자열의 모드 출처, 자동 원문 병기를 `translation`에 수동 삽입하지 않음.
- 작업 종류: 데이터 번역의 누적 소스, 범위 밖 후보의 구조화 인계. **모드 원본과 C# 코드는 수정하지 않음.**

## B. 후보 원본 및 기존 데이터 전수 역대조

| 원본 / 경로 | 사용자 화면 | 원본 수 | 1차에 있었던 번역 | 원문 불일치 | 이번 신규 | 2차 뒤 보류 |
|---|---|---:|---:|---:|---:|---:|
| Rook `SPT-4.1.6/db/CustomLocales/en.json` | 무기 프리셋 이름 및 `Name` 로케일 | 118 | 82 | 0 | **36** | **0** |
| Rook `AddTraderWithAssortJson.cs` / `AddCustomTraderHelper.cs` 및 `base.json` | 룩 상인 이름·위치·소개 | 5 | 5 | 원본 코드 대조, 변경 없음 | 0 | 0 |
| Russian Special Forces Pack `Resources/db/CustomItems/**/*.json` → `locales.en` | 아이템 Name·ShortName·Description | 327 | 193 | 0 | **45** | **89** |

- Rook의 번역 기존 87개는 원본 en 118개 중 82개 + 상인 주입 필드 5개로 구성됩니다. `CustomLocaleService.CreateCustomLocales(...)`와 상인 locale transformer의 로드 경로를 확인했습니다. 36개는 **프리셋 이름 18종 × 원본의 bare 키/` Name` 2행**으로 구성되며 두 종류의 `display_type: default`를 기존 기준대로 유지했습니다.
- Russian SF Pack의 327개 원본은 **109개 아이템 × Name·ShortName·Description 3필드**입니다. 이미 등록된 193개는 모두 원본 `source`와 정확히 일치합니다. 신규 45개는 네 파일 그룹의 전체 **15개 아이템 × 3필드**입니다. Name/Description에는 `match_mode: item_decorated`를, ShortName에는 `match_mode: exact` 및 `display_type: default`를 **각 행마다 명시**하여 이전 193번째 행의 `exact` 상속으로 아이템 표시 방식이 바뀌는 문제를 방지했습니다.
- Russian SF Pack에서 **탄약 Name/ShortName은 원문 그대로 유지**하고 Description만 번역했습니다. `source`는 대소문자, 단위, 문장 부호까지 원문 그대로 저장합니다. VSSK/레일/총열덮개를 포함한 모든 아이템 설명의 `[영문 아이템명]`·`(모드명)` 표시는 기존 자동 처리에 맡기고 번역 본문에 넣지 않았습니다.
- Russian `EcoQuestHelper.ModifyQuests()`는 기존 퀘스트의 사용 무기 조건에 아이템 ID를 추가하나 새로운 퀘스트 표시 문장을 생성하지 않습니다. 게임 화면 텍스트 번역 후보에서는 제외했습니다. 내부 아이템 구성 필드·어셈블리 로그·트레이더 거래/설정 값 등은 번역 비대상입니다.
- Rook `SPT-4.0.13`은 이번 SPT 4.1.6 기준에서 **작업 제외**했으며 해당 원본이나 구버전 데이터를 수정하지 않았습니다. 별도 F12 설정/독립 UI 번역 경로는 이번 두 서버 모드의 제공 SPT 4.1.6 소스에서 확인되지 않았습니다.

- Russian SF Pack은 **실제 모드 GUID `com.wtt.russiansfpack`와 기존 번역 프로필의 `mod_id: mod_628a0eba3644`가 서로 다르나**, 글로벌 로케일 프로필의 기존 식별자를 유지했습니다. GUID가 다르다고 프로필 mod_id를 임의 수정하지 않습니다.
- 새 파일이나 새 프로필을 만들지 않고 기존 2개 프로필에 행만 추가했습니다. 두 JSON 모두 기존 행을 데이터/행 순서 그대로 보존했음을 기계적으로 비교했고, 나머지 프로젝트 파일 변경은 이번 인계 문서 1개뿐입니다. `source` / `key` / 기존 280개 번역 행 / 다른 모드 프로필 / 1차 F12 추가 파일은 보존했습니다.
- 기존 로케일 공급 방식에서 적용될 것으로 예상되는 데이터로, **컴파일된 DLL 또는 인게임 출력 자체는 검증하지 못했습니다.**

## D. 후속 작업에 보존할 범위

- Russian SF Pack의 미등록 원본 **89개**는 신규 아이템 그룹 4개의 번역이 아니라 대부분 다른 그룹의 `ShortName`이며, 예외적으로 신규 SVDM 소음기 3필드가 포함됩니다. 출처별 키 및 원문은 소스 ZIP 밖의 회차별 인계 파일 `remaining_russian_source.json`에 모두 기록했습니다. 후속 번역은 원본 ID 단위로 묶되 **기존 Name/Description을 다시 바꾸지 않습니다**.
- 나머지 전체 모드: `ISB-Special-Forces-2.0.0.zip`, `True-North-4.0.29.zip`, `ISB-Aishi-2.0.3.zip`의 원본-번역 정밀 역대조와 화면/서버/로케일 경로 조사가 남아 있습니다.
- 1차 보류: Under Fire의 F12 이외 건강 효과 UI에 표시될 수 있는 `Adrenaline` 훅. **완료로 변경하지 않음**.
- 모든 회차의 후보 상태는 소스 ZIP 밖의 `candidate_inventory.json` 및 `handoff.json`에 누적 기록됩니다. 이번 회차 종료 시 전 회차 후보 + Rook 36 + Russian 신규 45 + Russian 미완료 89 = 190개로 1:1 대조합니다.
