# 1.0.3 개발 — ArenaMode 0.1.1 캐릭터 선택 화면 실제 출력 경로 재조사 및 수정

## A. 이번 요청의 기준

- 애드온 누적 소스: `SPT-Korean-Addon-1.0.3-ArenaMode-0.1.1-CS0012-CS0103-Reference-Fix-Source.zip`. 이보다 과거 회차를 기준으로 되돌리지 않음.
- 원본 모드: 사용자 제공 `ArenaMode-0.1.1.zip`, 내부 `ArenaMode.Client` 원본 소스. `.csproj`에 어셈블리명 `maschine-ArenaMode.Client` 명시.
- 사용자 증거: 캐릭터 선택 화면의 `ARENA`, `SEPARATE MATCH`가 영어로 남아 있음. 이전 `독립 UI 번역 완료` 판정 철회.
- 이번 작업에서 직접 재확인: `AGENTS.md`, `docs/모드번역_작업절차.md`, `docs/응답전_필수확인.md`, `docs/번역작업안내서.md`, `docs/TRANSLATION_FORMAT.md`, `docs/prompts/translate_prompt.txt`, `docs/PARENT_PATTERN_AUDIT_1.7.14.md`, `docs/LOCALE_DISPLAY_1.0.0_KO.md`, `docs/배포_업데이트노트_작성지침.md`, `docs/번역대상_인계기록_양식.md`, `docs/DISTRIBUTION_LAYOUT.txt` 및 실제 C# 훅·JSON·기존 인계 기록.

## C. 적용 범위와 안전성

- 기존 `src/ArenaModeUiHooks.cs`에 **확인된 ArenaMode.Session 타입/메서드만** 추가하고 이미 존재하는 원문 조회 로직을 재사용함. 별도 번역 엔진·원본 모드 DLL·전역 TMPro/Unity 훅·새 참조 DLL을 추가하지 않음.
- `src/SmallUiLiteralHooks.cs`에서 동일한 `ArenaSideSelectionLayout` 메서드를 패치하던 이전 항목을 제거해 중복 Harmony transpiler 방지. 기존 `ArenaPanel`과 `TacticalBuyPanel`은 그대로 유지.
- 언어가 한국어가 아니면 원본 출력. 기존 `TranslateVisible`의 정확한 원문 일치 및 언어 검사 사용. 원본 게임의 내부 `Arena` 식별자/세션 모드 값은 변경하지 않음.
- 캐릭터 선택 이외에 `ArenaSessionModeCaptionLedger`의 `ARENA ZONE`은 원본 상태 복원 비교 조건에 사용됨. 이 내부 텍스트를 무작정 치환하면 복원 동작이 깨질 수 있어 **미수정/미완료**.
- 기타 미완료 검토 후보: `ArenaCompactMapInfo`의 `SELECT A MAP` 등 직접 표시 문자열, 동적으로 합성되는 HUD/킬피드, 원본 자체에서 이미지로 표시되는 요소. 각 출력 지점과 기존 훅 범위를 먼저 확인해야 하며 '100% 한글화'라 보고하지 않음.

## D. 실제 검증과 제한

- 수정 대상은 `src/ArenaModeUiHooks.cs`, `src/SmallUiLiteralHooks.cs`, `translations/ArenaMode.json`, 관련 기존 회귀 테스트 및 신규 캐릭터 선택 테스트, 이 문서.
- 번역 데이터의 기존 항목·아이템 키와 원본 `source`, F12 `section/key/values`는 보존. 신규 2행은 Arena UI 화면 설명 전용.
- `python tools/validate_translations.py`, `python tools/verify_workflow.py source`, `python tools/verify_workflow.py documents`, `python -m unittest discover -s tests/WorkflowChecks -p 'test_*.py' -q` 수행.
- C# 컴파일/실제 DLL/`dist` 빌드/인게임 적용 확인은 이 환경에 `dotnet`이 없어 **미실시**. Python 회귀 테스트 통과를 컴파일/실게임 검증으로 주장하지 않음.
