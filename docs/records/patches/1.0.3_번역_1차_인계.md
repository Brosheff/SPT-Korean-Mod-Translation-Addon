# 1.0.3 작업용 번역 인계 — 1차 (2026-10-15)

> 이 문서는 공개 업데이트 노트가 아닌 개발·번역 인계 기록입니다. `1.0.3` 목표 작업 중이며 클라이언트·서버의 실제 버전은 아직 `1.0.2`입니다. 배포·인게임 번역 검증 완료를 의미하지 않습니다.

## A. 기준과 범위

- 요청: 제공된 일곱 모드를 여러 회차로 나누어 번역하고, 모든 후처리를 `docs/모드번역_작업절차.md` 및 관련 문서대로 수행.
- 누적 기준: 제공 ZIP `SPT-Korean-Mod-Translation-Addon-SPT4.1.6-1.0.0.zip` (내부 프로젝트 버전 1.0.2), SHA256 `890ecf36b60ba38b6f4132fa1952c18492e94bdbd30a57e75f14005a02cfdc68`.
- 1차 원본: `UnderFire-1.0.0.zip` (GUID `com.harmonyzt.underfire`, 실제 BepInPlugin 버전 `1.0.0`); `SPT-DynamicItemWeights-master.zip` (GUID `de.tosox.dynamicitemweights`, 실제 PluginVersion `1.2.1`).
- 1차 범위: **두 모드의 일반 F12 설정의 이름·설명·분류**. 모드 원본·설정 저장값·내부 로직을 수정하지 않음.
- 읽은 지침: 상위 작업 절차, 번역작업안내서 0-1절, TRANSLATION_FORMAT, translate_prompt.txt, 번역대상_인계기록_양식, 배포 업데이트 노트 작성지침, VERIFY_WORKFLOW.
- 이전 누적 변경물: 제공된 1.0.2 ZIP. 본 ZIP은 1.0.3 **1차 누적 개발 소스**이며 다음 회차 기준으로 사용.

## D. 역방향 검증 및 결과물

- 원본 → 결과: Under Fire `Config.Bind` 11개, Dynamic Item Weights `Config.Bind` 3개가 새 F12 프로필에 모두 존재. 분류 3+2개 포함, 별도 효과 표시 1개는 보류로 인계.
- 결과 → 코드: 두 GUID는 원본 BepInPlugin 상수와 일치. F12 번역은 기존 프로필 로더에서 탐색 가능한 위치에 저장. 인게임 표시 검증은 실시하지 않음.
- 보존: 기존 `translations/*.json` 109개, 기존 `config-ui` 109개는 번역 데이터 수정 없음. `tools/build_supported_mods.py`의 명시적 GUID→지원명 매핑만 2개 추가.
- 정적 검사: `python tools/verify_workflow.py source` / `python tools/validate_translations.py` / `python tools/verify_workflow.py documents` / `python -m unittest discover -s tests/WorkflowChecks -v` 통과(30개).
- 후보 인계 검사: 독립 JSON 20개 후보와 상태 20개를 `verify_workflow.py handoff`로 비교해 통과. 후속 작업이 남아 `--require-complete`를 사용한 릴리스 준비 판정은 하지 않음. 개발 기록 JSON은 소스 및 설치 ZIP에 포함하지 않음.
- C# 컴파일: **미실시** (`dotnet` SDK가 이 실행 환경에 없음; 이번 차수 C# 소스는 미변경).
- 설치용 배포 ZIP 생성: **미실시**, 이번 회차는 누적 소스 전달용임.
- 실제 게임 표시: **미실시**.
- 원본 모드 ZIP 수정/설치 파일 삭제: **없음**.

## F. 다음 회차 시작 조건

1. 이 **1차 누적 개발 소스 ZIP**을 새로운 기준으로 삼고 업로드된 원본 ZIP의 변조 여부·버전을 다시 확인.
2. `config-ui/com.harmonyzt.underfire.json`, `config-ui/de.tosox.dynamicitemweights.json`은 이미 추가했으므로 중복 생성·재번역하지 않음.
3. 새로운 모드를 시작할 때는 실제 원본 키/F12 UI/메시지·훅 후보를 별도로 전수 조사, 인계 기록을 추가하고 역대조.

5. 최종 1.0.3 배포 검증 전까지 `note/update.md`에 개별 차수 개발 내역을 추가하지 않음.
