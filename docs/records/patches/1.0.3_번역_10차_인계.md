# 1.0.3 번역 작업 인계 — 10차 (Under Fire 실제 게임 증거 및 소급 표시명 처리)

> **개발용 중간 소스.** 프로젝트 DLL 메타데이터는 여전히 1.0.2. 이번 회차는 9차 누적 개발 소스를 기준으로 구현/정적 검증까지 수행. 새 소스의 **C# 빌드 및 수정 후 인게임 재검증은 미완료**.

## A. 기준·조사

- 시작 소스: `SPT-Korean-Addon-1.0.3-Development-Batch9-Source.zip`; 원본 모드 `UnderFire-1.0.0.zip` (`Plugin.cs`, `Adrenaline.cs`). 기존 `translations/Under Fire.json`의 `Adrenaline` → `아드레날린`은 보존.
- 사용자 게임 로그(`LogOutput.log`): `Under Fire 1.0.0`이 먼저 로딩되고 `EFTEffectManager: registered 'Adrenaline'`을 출력한 뒤 애드온이 로딩되며 `[UnderFire:registered-before-hook]` 경고. 효과 실사용 로그도 있음.
- 사용자 스크린샷(건강 상태, 머리): `Adrenaline (53)` 영문으로 표시되어 **기존 방식의 UI 미번역 재현**.
- 원본 SPT 모드 `UnderFire.Plugin.Awake`: `EffectsManager.RegisterEffect<Adrenaline>` 호출 시 `EffectOptions.DisplayName = "Adrenaline"`, 반환 `EffectRegistration`을 `private static _adrenaline`에 보관함.
- 외부 원본 API 소스: `https://github.com/harmonyzt/EFTEffectManager`의 `EffectsManager.cs`는 `Registrations` 및 `DisplayNames` 정적 사전을 확인할 수 있음. `RegisterEffect<T>`는 효과 타입명(Adrenaline)을 키로 `DisplayNames`에 표시 문자열을 저장함. `Patches/UiPatches.cs`의 `LocalizedValuePatch.Prefix`는 `LocalizationManager.LocalizedValue(string,string)` 호출 시 `DisplayNames.TryGetValue`를 수행해 UI로 반환함. **현재 공개 소스 기준 근거**로, 사용자의 설치 DLL에서 동일한 구현인지 빌드·실행으로 별도 검증 필요.
- 준수 지침: `docs/모드번역_작업절차.md` → `번역작업안내서.md` 0-1절 → `TRANSLATION_FORMAT.md` → `prompts/translate_prompt.txt` → 인계 양식 → `tools/VERIFY_WORKFLOW.md`.

## B. 변경 범위 및 효과

| 대상 | 수정 | 주의점 |
|---|---|---|
| `src/SmallUiLiteralHooks.cs` | `SyncUnderFireDisplayName`을 `EnableUnderFireEarly`에 연결. `UnderFire.Plugin._adrenaline`에서 **실제 효과 등록**을 확인한 후, 효과 관리자의 `Registrations[typeof(UnderFire.Adrenaline)]`가 동일 객체인지 검증하고 `DisplayNames["Adrenaline"]` **한 항목만** `아드레날린`으로 동기화함. | 모든 필드/타입 및 기존 값이 예상과 맞지 않으면 아무 것도 수정하지 않고 종료. 기존 효과를 재등록하거나 게임 UI 전역 훅을 추가하지 않음. |
| `src/SmallUiLiteralHooks.cs` | 언어 변경 시 `RefreshLanguage()`가 등록된 표시명 사전도 동기화함. | `kr`/`kr-en`은 번역, 그 외 언어는 `Adrenaline` 복구. 실제 게임의 기존 열린 화면에서 재조회되는지는 미확인. |
| `src/Plugin.cs` | 초기 실제 동기화가 발생한 경우에만 `UnderFire:display-name-synced` 정보 로그 출력. | 조기 훅의 범위는 기존 `UnderFire.Plugin.Awake`로 유지, 다른 UI 훅은 기존 `Start()`에서 활성화. |
| `tests/WorkflowChecks/test_underfire_display_scope.py` | 등록 객체 일치, 효과명 사전 단일 항목 수정, 다른 효과/원본 로직 비변경, 언어 변경 갱신, 로그 조건을 정적 검사하는 테스트 추가/갱신. | C# 런타임/게임 내 테스트를 대체하지 않음. |

기존 번역 JSON, F12 설정, ISB 및 기타 모드 코드는 변경하지 않음. 새 번역 문자열/프로필 추가 0개. 원본 게임·Under Fire·EFTEffectManager 코드/DLL은 변경하지 않음.

## C. 후보 역대조·검증 단계

- 후보 552개 유지, 기존 완료/보류 분류 유지. `uf:effect:Adrenaline`의 적용 증거 토큰을 새 사전 기반 동기화 코드로 갱신. 미확인 ISB/Aishi 2개는 그대로 보류.
- 번역 스키마, 소스 정적 검사, 워크플로 단위 테스트, 후보-인계 1:1 검사, 지원 목록·문서 검사는 같은 회차에 실행하고 결과 로그를 별도 인계 ZIP에 보존.
- **유효성 한계:** 원본과 공개 API로 표시명 조회 방식까지 확인됐으나, 설치된 EFTEffectManager 바이너리의 실제 구조와 1.0.3 DLL 컴파일·실행·언어 전환·스크린샷 재확인은 미실시. 기존 인게임 스크린샷은 **수정 전 실패 증거**이지 수정 후 성공 증거가 아님.
- 원본 모드/다른 모드 효과/영문 UI는 필드명·타입 검사 실패나 비한국어 모드에서 원래 문자열로 남도록 설계. 효과 시간·체력·스태미나·이벤트를 건드리지 않음.
