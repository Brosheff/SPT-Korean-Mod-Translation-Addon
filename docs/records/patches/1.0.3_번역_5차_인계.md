# 1.0.3 번역 작업 인계 — 5차 (2026-10-15)

> 개발 중간 기록입니다. **번역 JSON 작성 및 정적 검증** 단계이며, 전체 프로젝트 버전은 **1.0.2**를 유지했습니다. 컴파일된 1.0.3 DLL, 설치 ZIP 또는 게임 내 표시 확인을 뜻하지 않습니다.

## A. 기준·원본·회차 범위

- **누적 소스:** `SPT-Korean-Addon-1.0.3-Development-Batch4-Source.zip`의 모든 기존 파일과 1~4차 인계 기록을 보존합니다.
- **원본 모드:** 업로드된 `True-North-4.0.29.zip`의 `server/Resources/db/CustomQuests/**/Locales/en.json`, `server/Resources/db/CustomLocales/en.json` 및 `server/Resources/db/CustomQuests/prapor/Quests/prapor_Quests.json`을 직접 대조했습니다.
- **작업 지침:** `docs/모드번역_작업절차.md` → `번역작업안내서.md` → `TRANSLATION_FORMAT.md` → `prompts/translate_prompt.txt` → `번역대상_인계기록_양식.md` → `tools/VERIFY_WORKFLOW.md`를 적용했습니다. 부착물/무기 약어 및 퀘스트 발화자·목표 규칙을 보존했습니다.
- **회차 범위:** 4차에서 보류한 True North 신규 로케일 키 92개와 기존 원문 불일치 54개. 다른 모드나 원본 ZIP, C# 훅, F12 파일은 수정하지 않았습니다.
- **적용 채널:** 기존 `translations/C11 - True North.json`의 `channels.locale`. 기존 `mod_id: mod_700ec7e0d1d4`, `mod_name: C11 - True North` 유지. 적용 경로는 기존 `src/ClientLocaleModOverlay.cs`의 로케일 프로필이며, 인게임 동작은 미검증입니다.

- **번역 내용 변경 예:** 소음기 지정 모델 MFMD, .338 처치 대상 제한 해제, 탄약·부품 및 SSD/플래시 드라이브 변경, 발견 상태(found in raid), 개조 요건 인체공학 55+·반동 280 미만, 세관/해안선 처치 지점, 위스키 숨기기, 퀘스트 메시지 추가 요구 내용을 새 원문에 맞췄습니다.
- **완전한 후보 대조:** 동반 개발 인계 ZIP의 `candidate_inventory.json`/`handoff.json`(1~5차 누적 549개 후보), `true_north_source_changes.json`(원문 변경 54개 전후와 한국어 변경 여부), `true_north_skipped_empty_keys.json`(비대상 81개 및 원본 경로), `batch5_summary.json`을 참고합니다. 개발용 JSON은 프로젝트 및 설치 ZIP에 넣지 않았습니다.
- **일치 방식:** 신규 11행은 `match_mode: exact` 명시. 기존 54행은 기존 `match_mode` 및 `display_type` 메타데이터를 유지해 고유 표시 분류를 변경하지 않았습니다. `key`, 원문·번역 외 필드 및 기존 4차 작업 결과는 유지했습니다.

## C. 후속으로 남긴 미확인 경로

5차에서는 True North의 **현재 원본 비공백 로케일 누락과 원문 불일치를 모두 해소**했습니다. 다만 로케일 JSON이 게임에 주입되는지와 직접 UI 소스의 표시 동작은 빌드·게임 확인이 필요합니다. 다음 범위는 4차 인계에서 그대로 보류하며 임의 별도 패치를 만들지 않습니다.

| 잔여 대상 | 상태·근거 |

| ISB Special Forces 알림 5개 호출부 | 직접 `NotificationManagerClass.DisplayMessageNotification` 출력. 애드온 연결 미검증으로 **보류**. |
