## A. 작업 기준 및 읽은 문서

- 기준 소스: `SPT-Korean-Addon-1.0.3-COTI-More-Energy-Description-Fix-Source.zip` (사용자가 직전 턴에 확인한 최신 누적 소스)
- 모드 원본: `ArenaMode-0.1.1.zip`, 내부 `ArenaMode-0.1.1/ArenaMode.Client`, `ArenaMode.Server`, `ArenaMode.Shared`
- 클라이언트 GUID: `com.maschine.ArenaMode`; 클라이언트 어셈블리: `maschine-ArenaMode.Client`
- 필수 읽기: `AGENTS.md`, `docs/모드번역_작업절차.md` 0·0-A 및 관련 절, `docs/응답전_필수확인.md`, `docs/번역작업안내서.md`, `docs/TRANSLATION_FORMAT.md`, `docs/prompts/translate_prompt.txt`, `docs/번역대상_인계기록_양식.md`
- 번역 범위: 원본 모드의 실제 로케일, F12 기본 설정, 확인된 아레나 독립 UI의 리터럴 문자열. 원본 모드 파일 변경 없음.

## B. 원본 → 번역·연결 대상

- F12 원본 `config.Bind` 조사에서 직접 184개가 확인되었습니다. 이 중 내부 숨김 6개와 재사용 템플릿 2개를 제외하고, 실제 바인딩되는 재사용 설정 9개와 정보 패널 17개를 대조해 총 **202개 사용자 표시 설정**을 등록했습니다. 내부 `Hide` 마이그레이션 키는 포함하지 않았습니다.
- `ArenaConfigMenuLayout`이 BepInEx의 기본 저장 키를 실제 F12 표시명으로 바꾸므로, `source_display_name`은 **실제 `I`/`Pct`의 표시명**으로 기록했습니다. `section`과 `key`는 변경하지 않았습니다.
- 문자열 보간을 포함한 C# 설명 원문은 런타임 표시값으로 복원했습니다. `ArenaHealthPickup.Amount`은 150, `ArenaFirePolicy.DamagePerSecond`는 **100**으로 확인했으며 소스 식별값에 보간식 `{...}`를 남기지 않았습니다.
- 동작 비교·내부 Unity 게임 오브젝트 이름에 쓰이는 문자열 `Instant`, `Seconds `, `Kills `는 **`small_ui`에 추가하지 않았습니다**. 해당 코드를 번역하면 게임 모드 분기나 버튼 이름이 달라질 수 있습니다.
- 모드가 동적으로 조합하는 HUD/점수·킬피드·상점 제목, `Modes/ArenaModeCatalog.cs` 등에서 별도 캐시된 게임 모드 설명/선택값, 사용자 설정 값/enum 및 기타 UI·팝업은 **전체 번역/적용 확인 범위가 아닙니다**. 독립 UI 전부 번역했다고 주장하지 않습니다.

## C. 구현과 범위 제한

- `translations/ArenaMode.json`: Arena Molotov 로케일 3개 + `small_ui` 정확 일치 67개.
- `config-ui/com.maschine.ArenaMode.json`: F12 설정 202개, 한글 표시명·설명, 원문 및 GUID 유지.
- `src/SmallUiLiteralHooks.cs`: 모드 소유 8개 타입에만 대상으로 등록하고, 실제 원본 리터럴이 포함된 메서드에만 Hook을 적용하도록 기존 동작을 재사용. **UnityEngine.GUI/GUILayout 같은 전역 훅 없음**. 로드 지연 어셈블리 허용 목록에 명시적으로 `maschine-ArenaMode.Client` 추가.
- `tools/build_supported_mods.py`와 생성된 `note/번역지원모드목록.md`: ArenaMode 신규 지원으로 표시. 애드온/모드 자체 버전은 변경하지 않음.
- `tests/WorkflowChecks/test_arenamode_011.py`: 원본 아이템 키, 실제 F12 이름 및 숨김 설정, UI 훅의 정확한 대상과 안전 제외 사례를 검사. 기존 Under Fire의 AssemblyLoad 허용 목록 회귀 단언도 변경된 허용 목록만 반영하고 조기 Under Fire 전용 조건은 보존.
- 원본 모드 소스/DLL/리소스, 기존 다른 모드 번역, `note/update.md` 변경 없음.
