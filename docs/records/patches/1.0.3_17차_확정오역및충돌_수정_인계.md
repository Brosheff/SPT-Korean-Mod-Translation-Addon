## 의도적으로 보류한 사항 (실행 자료 없이는 임의 수정 금지)

- **동일 키지만 서로 다른 영어 `source`를 가진 9그룹**은 서로 다른 원본 버전/모드 후보일 수 있으므로 일괄 합치거나 삭제하지 않음. 각 그룹의 상세 후보는 동봉 `1.0.3_17차_수정_상세내역.json` 참고.
- Russian SF Pack의 소음기 `6ab05288b07a9b85e5577d0e Name/Description`: 원본 `VSK`는 확인됐지만 게임의 `VKS` 변형은 미확인. `source_variants`를 추측으로 추가하지 않음.
- VKS 총구제퇴기 15차 수정 후 적용 여부도 아직 인게임으로 재확인하지 못함.
- 다른 모드가 원문을 변형한 경우 실제 서버 로케일 자료 없이는 전수 검증 불가.

## 검사 및 코드 보호

- `tools/audit_locale_integrity.py` 추가: **명시 장탄수 1:1 비교** 및 **동일 키+동일 원문인데 번역이 다른 충돌**을 탐지. 영어 `source` 자체가 다른 후보는 허용하며 동등하다고 가정하지 않음.

- 본 검사는 모든 문장/모든 숫자 오역의 의미상 교정을 보장하지 않음.
