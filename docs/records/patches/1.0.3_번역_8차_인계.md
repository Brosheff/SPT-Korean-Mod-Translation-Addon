# 1.0.3 번역 작업 인계 — 8차 (2026-10-16)

> **1.0.3 개발 중간 소스**. 프로젝트/플러그인 표기는 1.0.2 유지. 이번 변경은 정확한 소스 훅의 설치 시점 개선과 기존 `locale_additions` 1개 등록입니다. C# 컴파일·SPT 게임 내 실제 표시 확인 전이며, **완전 적용을 보증하지 않습니다**.

## A. 기준, 범위와 확인 문서

- 누적 소스: `SPT-Korean-Addon-1.0.3-Development-Batch7-Source.zip`; 기록: `SPT-Korean-Addon-1.0.3-Batch7-Inventory-Handoff.zip`.
- 재대조 원본: `UnderFire-1.0.0.zip`의 `UnderFire-1.0.0/Plugin.cs` (`RegisterEffect<Adrenaline>`), `ISB-Special-Forces-2.0.0.zip`의 `Plugin/Components/ISBAishiRaidResultUiFallback.cs`, `ISBAishiRaidResultInjector.cs`, `ISBLocale.cs`, `Server/db/CustomLocales/{en,po,pt}.json`. Aishi의 ID 두 개는 7차 조사 근거를 유지하며 새 조건이 제공되지 않아 수정하지 않았습니다.
- 지침 재확인: `docs/모드번역_작업절차.md`, `docs/번역작업안내서.md`(0-1절 포함), `docs/TRANSLATION_FORMAT.md`, `docs/prompts/translate_prompt.txt`, `docs/번역대상_인계기록_양식.md`, `tools/VERIFY_WORKFLOW.md`.
- 범위는 이전 회차의 미완료 UI 연결 중 **Under Fire 효과 등록 시점**, **ISB 결과 섹션 조회 키**이며 무관한 모드/로케일/기존 확정 번역을 수정하지 않습니다.

## B. 원본 → 결과물 / 적용 경로

| 후보 | 원본 근거 | 작업·로더 연결 | 정적 상태 / 미확인 |
|---|---|---|---|
| `uf:effect:Adrenaline` | Under Fire `Plugin.Awake()` → `EffectsManager.RegisterEffect<Adrenaline>` → `EffectOptions.DisplayName = "Adrenaline"` | 기존 `translations/Under Fire.json`의 `small_ui` 행 **변경 없음**. `SmallUiLiteralHooks.EnableUnderFireEarly()` 추가 및 `Plugin.Awake()`에서 `EditableProfiles` 로드 직후 **오직** `UnderFire.Plugin.Awake` 대상으로 먼저 설치. 나머지 기존 Small UI 훅은 `Plugin.Start()`에서 기존 Harmony 객체로 활성화. 조기 AssemblyLoad 이벤트도 UnderFire 어셈블리만 수신 후 대상 정확 일치 조건으로 패치하며, 기존 중복 패치 가드 사용 | **소스 및 정적 검사 통과**. Under Fire 쪽 `Awake`가 애드온보다 먼저 실행됐다면 과거 등록 문자열을 바꾸지 못함. 실제 로드 순서 및 게임 내 효과명 미확인 |

| `sf:raidresult:independent` | 모드의 결과 화면 `LooksLikeRaidResults()`, `FindHeader()`는 영문/포르투갈어 제목 문자열로만 판별하며 한국어 UI 헤더 목록은 제공되지 않음 | 원본 결과 화면 DLL 및 소스는 수정하지 않음. 번역 키 1개가 추가됐어도 섹션 복제 fallback의 한국어 헤더 감지는 별도로 검증해야 함 | **보류**. 결과 화면 전체 연결/제목 인식/기본 native injector 런타임 호출 미확인 |

주의: `locale_additions`의 `source`는 영문 UI 제목을 추측한 값이 아닙니다. 미등록된 조회 키 자체가 반환될 때의 정확한 fallback 토큰입니다. 포르투갈어의 `Reputação` 및 다른 기존 번역을 강제로 덮어쓰지 않습니다. 결과 화면의 한국어 제목 문자열을 추측해 `StandingTitles` 등에 삽입하는 훅도 제작하지 않았습니다.

## C. 후보 역대조와 검증 수준

- `candidate_inventory.json` / `handoff.json`: 총 **552개** 그대로, 번역·소스 연결 370, 원문 유지 93, 비대상 87, 보류 2. `sf:raidresult:standing-section-key`만 보류 → `locale_additions` 근거가 있는 작성 상태로 이동. `uf:effect:Adrenaline`은 훅 등록 근거에 `Plugin.Awake` 조기 설치를 추가했습니다.
- 보류: `sf:raidresult:independent`(한국어 헤더/실제 레이드 화면), `aishi:bare:refs`(퀘스트 조건 참조 두 ID). Under Fire는 별도 **로드 순서 조건**으로 실제 표시 미확인입니다.
- 검증: 원본 조회 키 존재, 설정/번역 정적 검사, `verify_workflow.py handoff`, docs 검사, 지원 목록 생성 및 워크플로 회귀 테스트 **34개**. 이 검사는 **컴파일이나 Unity/IL 런타임 확인이 아닙니다**.
- 컴파일/설치 ZIP/인게임: **미실시**. 작업 환경에서 `dotnet`, `csc`, `mcs`, `msbuild`, `mono`, `pwsh` 실행 파일을 찾지 못했습니다. 설치용 빌드 ZIP은 만들지 않았습니다.
- 변경 파일은 아래 표로 한정되며 이전 소스의 번역 데이터 행과 기존 코드 대상은 보존합니다.
