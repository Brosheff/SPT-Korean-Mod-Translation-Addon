# 1.0.3 개발 인계 — ArenaMode 0.1.1 독립 UI·게임플레이 맥락 보완

## 기준과 작업 범위

- **기준 애드온:** `SPT-Korean-Addon-1.0.3-ArenaMode-0.1.1-Translation-Source.zip` (사용자의 최신 누적 번역 소스).
- **기준 모드:** `ArenaMode-0.1.1.zip`, 원본 `ArenaMode.Client` C# 소스.
- **선행 감사:** 사용자 제공 `ArenaMode-0.1.1-독립UI-용도별-재감사.md`.
- **확인한 프로젝트 규칙:** `AGENTS.md`, `docs/모드번역_작업절차.md`, `docs/응답전_필수확인.md`, `docs/번역작업안내서.md`, `docs/TRANSLATION_FORMAT.md`, `docs/prompts/translate_prompt.txt`.
- **원본 ArenaMode ZIP, 원본 모드 DLL, 게임 서버 파일:** 변경하지 않음.

## 수정의 필요성 및 확정 원인

기존 `small_ui` 67개 행은 정적 C# `ldstr` 교체 방식이며, ArenaModeCatalog/MutatorSelection/AreaSelectionState 등 **데이터 생성 클래스에서 View에 전달하는 문자열**은 상기 8개 훅 클래스의 정적 리터럴 검사로 처리되지 않는다. 또한 `ScorePanel`과 `ArenaPowerupPanel`은 수치/색상 태그를 포함하는 텍스트를 동적으로 생성하므로 기존 exact JSON으로는 완전 일치하지 않는다. 이전 59개 회귀 테스트의 통과가 실제 화면 전수 번역의 증거는 아니다.

## 데이터 변경

- `translations/ArenaMode.json`: `small_ui` **기존 67행 → 현재 208행**. 게임 모드명/설명/규칙/부활·장비 방식, 변형 규칙과 제한 사유, 지역/인원 문구, 데스매치·좀비 제어, 점수 HUD·강화 효과·킬피드 사망 원인 등을 추가.
- 기존 `Powerups`는 플레이어 표시 문구가 아니라 HUD GameObject 이름이므로 번역 대상에서 제외.
- `Instant`, `Off`, `None`, `Free-for-all`, `All vs player`는 데이터에 화면 번역으로 등록하되 **C# 정적 리터럴 후킹에서 명시적 제외**한다. 게임 분기·저장 선택값을 바꾸지 않고 렌더링 값만 한국어화한다.
- `config-ui/com.maschine.ArenaMode.json`: F12 설정 202개, `section`, `key`, `source_display_name`, `source_description` 변경 없이 **설명 6행의 `translation_description`만 보완**. 대상: `Movement/BunnyhopEnabled`(6%·25%·12m/s·입력 우선순위), `Performance/MaxCorpses`(숨긴 시체 수색 불가·0), `Character/LegInjurySlowdownReductionPercent`(50 수치·달리기 제한), `Movement/CarryWeightLimitMultiplier`(1·2), `Bot movement/BotWalkSpeedMult`(문·모퉁이·저FPS), `Zombie/CrowdEnabled`(12/16/22m·80m·시야/회피 예외).
- 기존 `locale` 화염병 3개 행과 다른 모드 번역·F12 파일은 변경하지 않음.

## 실제 출력 연결 경로

- `src/SmallUiLiteralHooks.cs`의 기존 범위 지정 정책 안에서, **지정된 ArenaMode 0.1.1 UI 클래스의 `TMP_Text.set_text` 호출만** Harmony Transpiler로 기존 번역 프로필에 연결. 클래스: `ArenaModeSelectionView`, `ArenaMutatorsView`, `ArenaAreaSelectionView`, `ArenaEquipmentChoiceView`, `ArenaDeathmatchRulesView`, `ArenaZombieRulesView`, `ArenaTdmMatchRulesView`, `ScorePanel`, `ArenaPowerupPanel`.
- 같은 UI 메서드 내 `HoverTooltipArea.SetMessageText(string,bool)` 호출은 소스에서 확인된 오버로드만 별도 래퍼로 처리하고 나머지 상태·선택 이벤트를 보존.
- `ArenaScoreboardPresentation.Label(Rect,string,GUIStyle,Color)`만 UI 출력 시점에서 치환. 플레이어가 정한 이름은 보존하고 `(YOU)` 표시 접미부만 처리.
- `KillfeedText.DeathCause(string)`의 **반환값만** 번역. 내부 사망 유형(`DamageKind`)은 변경하지 않음.
- 정해진 HUD 템플릿에 대해서만 숫자·타이머·`<color>`/`<size>` 태그를 보존하며 표시 토큰을 교체. 전역 문자열 유사도 치환·Unity 전체 UI 후킹 없음.
- 한국어 외 언어에서는 원문을 보존. 동적으로 갱신되는 번역 TMP는 기존 언어 전환 추적 목록에 원문을 보관하여 갱신한다. 게임 내 실제 언어 전환 동작은 아직 미검증.

## 검증과 남은 작업

- 113개 번역 프로필 JSON 검사, 소스/문서 워크플로 검사, WorkflowChecks **63개** 통과.
- Arena `small_ui` **208개 source 문자열 모두 ArenaMode 0.1.1 소스에 실제 존재함**을 정적 텍스트 대조로 확인(출력 여부까지 입증하지는 않음).
- **C# 컴파일 미실시:** 환경에 `dotnet` / `csc`가 없음. Harmony 패치 실제 메서드 연결·다른 모드와의 후킹 상호작용·실게임 언어 전환·인게임 표시 미검증.
- **의도적으로 보류한 경로:** `ArenaSessionModeCaptionLedger`의 `ARENA ZONE` 복원 규칙은 레이블 텍스트를 바꾸면 원본 복원이 실패할 수 있어 직접 치환하지 않음. 일부 `ArenaPanel` IMGUI 동적 게임 상태, 장비/모드 코드에서 조합한 복합 HUD 메시지, 로컬화되지 않은 보급품 알림은 게임 출력/정확한 안전 범위를 추가 확인해야 함.
- 전체 F12 202개 설명의 의미적 전수 교정을 수행했다고 주장하지 않음. 이번에 재감사에서 **누락이 확정된 6개**만 보완함.
- `note/번역지원모드목록.md`: 지원 채널(로케일·UI·F12)이 기존과 동일해 변경 불필요. `note/README.md`: 설치/버전 변경 없으므로 변경 불필요. `note/update.md`: 1.0.3 공개본 미확정 및 사용자 지시에 따라 **변경 없음**.
