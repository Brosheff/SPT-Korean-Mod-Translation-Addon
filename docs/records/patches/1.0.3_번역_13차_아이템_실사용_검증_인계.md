# 1.0.3 개발 인계 — 13차 아이템 번역의 실제 적용 검증

## 요청·증거

- 사용자는 Russian Special Forces Pack의 번역 데이터가 있음에도 게임에서 원문으로 보인다고 보고함.
- 1~12차 산출물은 소스 ZIP이며 설치용 DLL/데이터 배포본이 아니었다. 따라서 전달한 소스 ZIP만으로 게임 설치본이 갱신됐다고 증명할 수 없음.
- 실제 사용자 설치 폴더의 `Russian Special Forces Pack.json` 파일 존재/해시, `kr` 로케일 런타임 원문, 인게임 결과 화면은 확인되지 않았다. **실제 미적용 원인은 아직 확정하지 않는다.**

## 원본·데이터·로더 대조

- 원본 `Russian-SF-Pack-2.0.1.zip`의 `RussianSFPack/Resources/db/CustomItems` JSON에서 `locales.en` 109 아이템 × `name`, `shortName`, `description` = 327개를 추출하고 현재 프로필의 `key/source` 327개와 1:1 일치 확인. 원본 모드 파일은 변경하지 않았다.
- `translations/Russian Special Forces Pack.json`: `mod_id=mod_628a0eba3644`, `channels.locale` 327행, 키 중복·원문 불일치 없음.
- `src/EditableProfiles.cs`는 클라이언트 DLL 위치의 `translations/*.json`을 읽음. `src/AddonBridge.cs`와 `src/ClientLocaleModOverlay.cs`는 클라이언트 locale 합병 시 `kr`/`kr-en` 및 실제 런타임 `key/source`가 일치할 때 한국어 값을 덮어씀. 직접 JSON을 수정한 것만으로 실제 게임에서 통과했다는 뜻은 아님.
- 예시 이름: `6aac31fac35219b1cf4d2a84 Name`의 원문은 `VKS Vykhlop 12.7x55 bolt-action sniper rifle`, 번역문은 `VKS Vykhlop 12.7x55 볼트액션 저격소총`. 같은 아이템의 `ShortName` 원문/번역문은 모두 `VSSK`이므로 인벤토리 단축명이 `VSSK`로 그대로 보이는 것은 **원문 유지 규칙에 따른 정상 후보**이며 풀네임·설명까지 영문인 경우와 구별해야 함.
- `VSK` 표기 두 건은 원본 파일 자체의 표기이므로 적용 실패 수정 작업에서 임의로 원문을 변경하지 않음. 명칭 교정은 별도 번역 품질 작업으로 분리.

## 13차 조치 — 애드온 번역 데이터 경로 검증

- 현재 소스의 번역 JSON 111개를 `BepInEx/plugins/SPT_Mod_Korean_Addon/translations/` 구조로 묶은 **데이터 전용** 압축파일 `SPT-1.0.3-Translations-Data-Only-Install.zip`을 프로젝트 외부로 생성.
- 사용자 현재 번역 파일을 덮어쓰는 범위를 최소화하기 위해 Russian Special Forces Pack의 JSON 1개만 같은 경로에 포함한 `SPT-1.0.3-Russian-SF-Locale-Install.zip`도 프로젝트 외부에 생성.
- 데이터 전용 압축파일은 DLL/서버/원본 모드/새 훅을 포함하지 않음. 기존 애드온의 locale 오버레이가 설치돼 있고 같은 포맷을 읽는 조건에서만 효과가 있음. **정식 1.0.3 설치용 배포본이 아니다.**
- 실제 게임 폴더에 대한 수정은 하지 않았다. 사용자가 설치 파일의 백업 후 데이터 ZIP을 SPT 루트에 덮어써야 함. 게임 재시작 후 아이템 풀네임·설명과 단축명을 구분해 검증해야 함.

## 검증 상태 및 다음 확인

| 단계 | 상태 |
|---|---|
| 원본 327개 키/source vs 번역 327행 | 통과 |
| 전체 프로젝트 111개 번역 프로필 스키마 | 통과 |
| 기존 번역 로더 경로·문화권 검사 코드 확인 | 완료 |
| 설치 경로형 ZIP 목록과 CRC 검사 | 통과 |
| 실제 사용자 PC의 번역 프로필 설치·로드 확인 | **미확인** |
| 원본 서버가 반환한 KR locale과 JSON source 런타임 일치 | **미확인** |
| 아이템 인게임 이름·설명 표시 | **미확인** |
| 새 클라이언트/서버 DLL 컴파일 | **미실시(이번 작업은 JSON 데이터 패치)** |

이후 동일하게 영어로 표시된다면 현재 애드온 DLL의 실제 해시 및 설치 폴더의 JSON, 게임이 반환한 해당 키 로케일 값이 필요하다. 원문 일치 조건을 삭제하거나 소유권이 불확실한 다른 번역을 무차별 덮어쓰는 코드는 추가하지 않는다.
