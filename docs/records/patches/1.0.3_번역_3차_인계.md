# 1.0.3 작업용 번역 인계 — 3차 (2026-10-15)

> 이 문서는 **개발 중 인계 기록**이며 사용자 공개 업데이트 노트가 아닙니다. 프로젝트 버전은 1.0.2를 유지합니다. 번역 JSON 작성과 정적 검사 완료는 빌드·설치 ZIP 생성·게임 내 표시 확인과 구별합니다.

## A. 이번 작업의 기준과 대상

- 선행 기준: `SPT-Korean-Addon-1.0.3-Development-Batch2-Source.zip` 및 `docs/patches/1.0.3_번역_2차_인계.md`, 동반 인계 파일의 `remaining_russian_source.json`(89개), `candidate_inventory.json`, `handoff.json`.
- 원본: 업로드된 `Russian-SF-Pack-2.0.1.zip`의 `RussianSFPack/Resources/db/CustomItems/` 아래 소스 JSON 15개. 같은 압축의 `bin/Debug` 중복 출력물을 원본으로 섞지 않았습니다.
- 실제 원본 인벤토리: **109개 아이템 × Name·ShortName·Description = 로케일 327개**. 원본 `locales.en`의 키와 모든 영문 문자열을 압축파일에서 다시 추출하여 누적 프로필과 대조했습니다.
- 작업 범위: 누적 번역 238개를 변경하지 않고 **미등록 89개 키**를 추가합니다. 해당 89개는 ShortName 87개와 SVDM 소음기의 Name·Description 2개입니다(소음기의 ShortName도 87개에 포함).
- 작업 순서와 원칙: `docs/모드번역_작업절차.md` → `docs/번역작업안내서.md` → `docs/TRANSLATION_FORMAT.md` → `docs/prompts/translate_prompt.txt` → `docs/번역대상_인계기록_양식.md`를 준수합니다. `translation`은 번역 본문만 쓰고 코드가 붙이는 아이템 원문명·모드 출처는 직접 삽입하지 않습니다.

- 앞 회차의 Russian SF Pack의 기존 프로필 `mod_id: mod_628a0eba3644`를 유지했습니다. 모드의 실제 GUID `com.wtt.russiansfpack`와 다른 기존 식별자를 이번 회차에서도 변경하지 않았습니다.
- 89개 신규 행은 ShortName에 `match_mode: exact`, `display_type: default`, Name·Description에 `match_mode: item_decorated`를 명시합니다. 특히 기존 프로필 마지막 행의 match_mode 상속 문제를 막기 위해 신규 행 모두에 명시했습니다.

- 이번에는 신규 모드/채널/전용 UI 훅이 필요하지 않은 **기존 locale 데이터 추가만** 수행했습니다. 원본 모드·DLL·서버 웹 소스를 수정하거나 `extras`/독립 설치 패치를 만들지 않았습니다.
- 회차별 `candidate_inventory.json`과 `handoff.json`은 소스 ZIP **외부** 인계 기록으로 관리합니다. 직전 후보 190개 가운데 Russian 89개의 `blocked`를 `translated`로 변경했습니다. 후보 총수 **190**, 정적 근거가 있는 `translated` **189**, `blocked` **1**(Under Fire `Adrenaline`)입니다. 키별 상세 근거는 해당 별도 JSON에서 1:1로 확인할 수 있습니다.
- Russian 327개 원문 전체를 커버했지만, **인게임 UI에서 실제 표시된 결과는 확인하지 않았습니다.** 문서의 원본·키·번역 데이터 검증과 런타임 검증을 구분합니다.
