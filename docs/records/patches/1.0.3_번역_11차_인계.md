# 1.0.3 번역 작업 인계 — 11차 (Epic's All in One 5.0.2)

> 개발 중간 소스. 10차 누적 소스 기반, 게임 SPT 4.1.6 목표. 프로젝트 버전은 기존 1.0.2 유지. C# 빌드·인게임 확인은 미실시.

- 기준 소스: `SPT-Korean-Addon-1.0.3-Development-Batch10-Source.zip`.
- 원본 ZIP SHA256: `c702ffcabad2f6f285585c5a12ac1bf7b904be686e5792767e1a98a4e399e866`.
- 원본 코드: `EpicsAIO/ModMetadata.cs`; GUID `com.epicrangetime.aio`, 이름 `Epic's All In One`, 명시 호환 `~4.1.0`, 의존성 `com.wtt.commonlib ~3.0.4`. 원본 ZIP명 버전 5.0.2; 실제 빌드된 어셈블리 버전은 이 소스만으로 확정할 수 없음.
- 기존 애드온 프로필 `translations/Epic's All in One.json`: **기존 `mod_id`인 `mod_44c57e89dbd9` 유지**. 실제 모드 GUID와 다름을 명시하고 임의 교체하지 않음.
- 실제 로케일 제공 경로: `EpicsAIO/Resources/db/CustomLocales/en.json` 및 `EpicsAIO/Resources/db/CustomQuests/Badger/Locales/en.json`; 코드 `EpicsAIO.cs`의 `CustomLocaleService.CreateCustomLocales`/`CustomQuestService.CreateCustomQuests` 연결 확인.
- 문서: 최상위 작업 절차 → 작업 안내서 → `TRANSLATION_FORMAT.md` → 번역 프롬프트 → 인계 양식 → 검증 절차 순으로 확인.

## B. 번역 범위·대조

| 대상 | 원본 키 | 기존 등록의 일치 | 신규 추가 | 원문 불일치 |
|---|---:|---:|---:|---:|
| 메인 아이템·상인 로케일 | 1511 | 1323 | 188 | 0 |
| Badger 퀘스트 로케일 | 36 | 36 | 0 | 0 |
| 합계 | 1547 | 1359 | **188** | **0** |

- 신규 188개: 아이템 단축명 186개와 `Aimpoint CompM4s`의 Name/Description 각 1개.
- 신규 188개 중 **26개 한국어/표기 변경, 162개 모델명·약어 원문 유지**.
- 핵심 예시: `Aimpoint CompM4s reflex sight` → `에임포인트 CompM4s 반사 조준경`; `AKS Pic` → `AKS 피카티니`; `.300` 계열 총기 단축명 → `.300 블랙아웃` 표기; `DT FDE` → `DT 사막색`.
- 모델명·제품 이니셜·미분류 단축명은 원문 유지. 아이템 영문 이름과 모드 출처를 번역문에 수동 삽입하지 않음.
- **현재 프로필 1665행**: 원본 현재 키 1547개와 일치; 기존에서 이어받은 레거시 키 **118개는 원본에서 미확인이나 제거하지 않음**. 별도 `legacy_keys_preserved.json`에 키 목록 기록.
- 현재 원본 1547개 전부 키·source 1:1 대조, 신규 키·치환 변수 원문 보존. 같은 프로필의 기존 행 1477개는 바이트 수준의 JSON 객체 값 그대로 보존.

## C. 원본 표시 경로 조사 및 보류

- 메인 로케일은 WTT 공통 라이브러리의 `CustomLocaleService`; Badger 퀘스트는 `CustomQuestService` 등록 경로. 기존 애드온의 `locale` 채널로 번역 매칭하며 새로운 DLL 훅·F12 프로필 불필요.
- 원본 `EpicsAIO`는 서버 모드이며 이번 ZIP에 별도 클라이언트 Config.Bind/F12 플러그인, 전용 TMP/GUI 렌더링, 고유 웹 UI 파일 확인되지 않음. 별도 연결을 추정해 생성하지 않음.
- `Badger`의 거래 데이터/퀘스트 정의, 로깅·아이템 ID 등 내부 식별자는 번역 대상 아님. 재고 프리셋이나 상인 로직은 수정하지 않음.
- 원본 내 레거시 118개 키의 런타임 매칭 여부는 **미확인**이며 이전 번역 보존이 우선. 원본 코드와 애드온 로더의 정적 연결만 확인했으므로 실제 SPT에서 표시됐다고 주장하지 않음.
- 원본 모드 DLL·JSON·아이템 DB·서버 소스를 변경하지 않음. 사용자가 요청한 검사 코딩 정리는 **Under Fire의 임시 동기화 성공/실패 진단 로그 2개와 그 로그만 확인하던 단위 테스트 하나**에 한정. 표시명 동기화와 등록 객체 안전 검증, 언어 전환 테스트는 보존.
