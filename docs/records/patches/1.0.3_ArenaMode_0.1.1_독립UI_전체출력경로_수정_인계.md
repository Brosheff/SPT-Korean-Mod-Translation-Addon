# 1.0.3 — ArenaMode 0.1.1 독립 UI 전체 출력 경로 재감사·수정 인계

## A. 기준과 범위

- 기준 누적 소스: `SPT-Korean-Addon-1.0.3-ArenaMode-0.1.1-Character-UI-Scoped-Repair-Source.zip`; 원본: `ArenaMode-0.1.1.zip`.
- 읽은 절차: 루트 `AGENTS.md`, `docs/모드번역_작업절차.md`, `docs/응답전_필수확인.md`, `docs/번역작업안내서.md`, `docs/TRANSLATION_FORMAT.md`, `docs/prompts/translate_prompt.txt`, 부모 표시 패턴, 표시 규칙, 인계·배포 지침.
- 사용자 증거: 캐릭터 선택 화면의 `ARENA` / `SEPARATE MATCH` 잔류. 스크린샷의 두 문구만으로 검사 범위를 제한하지 않음.
- ArenaMode 전체 클라이언트 원본 429개 C# 파일의 직접 텍스트 출력 호출 위치를 검색하고, UI·HUD·동적 경기 상태·모드/서버 로직을 구별함. 부록에는 실제 텍스트 설정/IMGUI 호출 후보의 원본 상대 경로와 행을 기록함.

## C. 게임 로직 보호

- 원본 ArenaMode 파일·서버 소스는 수정하지 않음. `ArenaModeCatalog`·모드 ID·킬 판정·팀/관전자 식별자·F12 저장 키/enum·맵 선택값 등에는 Harmony를 설치하지 않음.
- 기존 `.csproj` / `references` / 배포 스크립트에는 새 DLL 의존성을 추가하지 않음.
- `GUI/GUILayout` 전역 API를 패치하지 않음. 모드의 확인된 클래스·메서드 내부에서만 IL의 정확한 표시 호출을 감쌈. 원문 불일치/비한국어에서는 원래 호출이 실행됨.
- `ARENA ZONE` 상태값을 원본 모드/원장 안에서 변조하지 않음. 한 번 변역한 레이블은 원래 문자열을 기억하여 복원하고, Native/비-Arena 레이블은 변경하지 않음.
- 번역 프로필의 원문 `source`, 키·아이템 ID·F12 설정은 이전값을 보존. `small_ui` 신규 문구만 추가하고 **기존 중복 UI 규칙 ID 1곳**은 원문과 번역은 유지하며 ID 충돌만 해소함.

## D. 남은 미확인 영역과 위험

- **게임 실행이 없어 100% 한글화를 증명할 수 없음.** 원본 정적 C# 소스는 실제 컴파일된 모드의 IL/실행 분기를 증명하지 못함.
- 일부 네이티브 EFT 매치메이커 화면은 원본 ArenaMode가 `ARENA ZONE` 텍스트를 쓰지 않는 경로가 존재함. 이를 확인되지 않은 전역 화면 패치로 덮지 않음.
- 유저 생성 이름, 봇 프로필 이름, 장비 이름, 지도 고유명사는 다른 데이터로부터 올 수 있어 임의 음역/전역 치환하지 않음. 상태·킬피드·동적 결과 중 아직 기록되지 않은 출력 템플릿은 실제 게임에서 확인 필요.
- 원본 직접 TMP/텍스트/IMGUI 후보 목록 **111곳** 외에 놓쳤던 `GUI.Window` 창 제목 2곳과 `GUILayout.Toggle` 설정 레이블 6곳도 추적·수정(총 후보 **119곳**). 수동 스코프 코드가 실제 런타임 메서드 IL에 적용되는지와 더 간접적인 출력 경로는 빌드·게임 실행 검증 필요.
- HUD의 무기·탄약 이름은 원본 게임의 `Localized()`를 사용하고, 탄창/부위 수치는 원본 로직이 관리함. 별도 검증이 필요한 경우 단축명/로케일 스냅샷 확인.
- 게임과 서버를 실행하지 못했으므로 **C# 실제 컴파일, dist 반영, 게임 UI 적용 전수 검증 모두 미실시**. 테스트나 문자수로 대체하지 않음.

## E. 문서 후처리

- `docs`에 인계 기록과 원본 UI 출력 호출 후보 인벤토리 추가. 기존 번역 관련 문서의 코딩 규칙은 변경하지 않음.
- `note/README.md`는 설치 방식/의존성/버전 불변으로 수정하지 않음. `note/번역지원모드목록.md`는 ArenaMode가 이미 등록되어 있고 지원 모드 자체는 바뀌지 않았으므로 수정하지 않음.
- `note/update.md`는 공개 1.0.3 확정 전 같은 버전 개발 중 수정이므로 **수정하지 않음**.
- 결과물은 수정된 **전체 개발 소스 ZIP**. 설치용 `dist`로 소개하지 않음.

## F. 정적 검사 결과 및 빌드 구분

- `python tools/check_csharp_delimiters.py`: 통과. **구문 구분자 사전 검사이며 C# 컴파일이 아님**.
- `python tools/validate_translations.py`: 113 프로필 통과.
- `python tools/verify_workflow.py source`: 통과. `python tools/verify_workflow.py documents`: 통과.

- `python tools/build_supported_mods.py` 후 지원 목록 해시 불변; `note/update.md` 원본 보존.
