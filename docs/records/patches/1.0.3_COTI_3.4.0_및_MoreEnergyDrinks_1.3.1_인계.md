**정확성/정책 메모**
- More Energy Drinks의 설명 원문에 공통 포함된 `Item added by Hood's More Energy Drinks Mod` 표기는 표시 코드가 모드명을 별도로 붙이므로 번역 본문에는 중복 작성하지 않았다. 해당 문구는 `source`에서 제거하지 않았다.
- `Rip It ` 단축명 원문 끝의 공백도 원본 그대로 보존했다. 설명의 위험 경고 및 카페인 함량 등은 번역에서 유지했다.
- **원본 자체의 불일치:** `ghost_peaches` 및 `ghost_swedish_fish`의 설명이 상품 이름과 달리 `Strawbango Margarita`라고 기술한다. 이 회차에서는 원문대로 번역했으나, **후속 사용자 요청에 따라 두 제품의 한국어 설명을 제품명에 맞게 교정했다.** 키·원본 `source`는 그대로 보존한다. 변경 후 상태는 [`1.0.3_COTI_MoreEnergyDrinks_설명불일치_교정_인계.md`](1.0.3_COTI_MoreEnergyDrinks_설명불일치_교정_인계.md)를 확인한다. 원본 모드 데이터는 변경하지 않는다.
- COTI 3.4.0의 Blazor 웹 설정 페이지(`Coti.Server.Web/Pages/*.razor`)와 화면에 표시하는 PNG 텍스처 기반 전원/모드 안내는 현재 애드온의 `locale`/F12/클라이언트 `small_ui` 채널과 연결되지 않는다. **번역 적용 미완료/검증 불가**로 남기며, 원본 모드의 웹·이미지 파일을 수정하거나 별도 패치를 만들지 않는다.
- `CotiSlotLocale.cs`의 장착 슬롯 레이블은 영어 약칭 `ECOTI` 등에 기반한다. 해당 문자열은 슬롯명으로서 원문 유지 대상으로 분류한다.

## 원본 역대조 및 검증 단계
- More Energy Drinks: 40개의 고유 템플릿 ID 각각에 정확히 3종 키가 있고, `EnergyDrinkInfo.json` 이름·단축명·설명 소스 값이 정확히 일치하는지 별도 검사한다.
- COTI: 위 8개 템플릿 ID 및 Name·ShortName·Description을 각 생성 코드의 원문과 대조한다.
- JSON 형식, 기존 번역/기타 파일 보존, 지원 모드 목록 동기화, 회귀 테스트 결과는 작업 종료 기록에 남긴다.
- **실제 SPT 4.1.6 서버 병합 로케일 미확보; 클라이언트 C# 재빌드·배포 생성·게임 실제 표시 미실시.** 원문 ZIP과 JSON 일치는 게임 적용 보장이 아니다.
- 공개용 `note/update.md`는 사용자 요청에 따라 **변경하지 않는다.** `note/번역지원모드목록.md`는 신규 프로필 등록에 맞춰 재생성한다.
