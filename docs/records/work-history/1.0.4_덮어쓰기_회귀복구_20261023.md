# 1.0.4 덮어쓰기 번역 회귀 복구 — 2026-10-23

## 사용자 증거와 문제

1.0.3에서 정상적으로 출력된 번역이 이전 3개 모드 업데이트 데이터를 덮어쓴 후 영어로 빠졌다는 사용자 보고. 과거 정적 검사 통과는 인게임 표시 확인과 다르며, 게임 로그/실제 런타임 로케일 스냅샷은 제공되지 않음.

## 정적 원인 및 영향

- 원본 1.0.3의 `ISB Aishi.json`과 이전 1.0.4 소스의 동일 키 비교에서 영어 `source` **152건**이 교체되어 이전 영어를 받으면 기존 정확 일치 로더가 해당 번역을 적용하지 못함.
- `ISB Special Forces.json`의 영어 `source` **6건**도 동일. 또한 `small_ui`에서 자막 원문 철자 `QUEESTIONING` → `QUESTIONING`이 바뀌면서 기존 철자 후보가 제거됨.
- `COTI` 프로필은 원문 교체가 없고 버전 정보만 변경. 다른 모드 번역 프로필은 원본과 현재 파일이 동일함.
- `source` 교체 자체가 게임에서 보고된 특정 미번역 키의 유일한 원인이라고 단정하지 않음. 런타임 값·설치 로그가 없으므로 그 점은 미확인.

## 수정

기존 클라이언트 DLL은 동일 키의 *서로 다른 프로필 후보*를 영어 원문별로 비교할 수 있음 (`src/ClientLocaleModOverlay.cs`의 `entries` 후보 리스트와 `Translate`). 구버전/신버전 번역이 의미상 다른 행이 있어, 모든 구버전 원문을 하나의 `source_variants`에 넣으면 과거 번역 뜻이 바뀌는 문제가 생김. 따라서 데이터 전용 호환 프로필 2개를 **같은 모드명 및 독립된 내부 mod_id로** 추가하여 다음을 보장하도록 수정함.

- `translations/ISB Aishi - 2.0.3 Compatibility.json`: 원본 1.0.3의 152개 정확 키·영문·한국어 대응 보존. 새 2.0.4 데이터는 원래 `ISB Aishi.json` 유지.
- `translations/ISB Special Forces - 2.0.0 Compatibility.json`: 원본 1.0.3의 6개 업적 설명 정확 대응 보존. 신규 2.0.1 데이터는 그대로 보존.
- `translations/ISB Special Forces.json`: 구버전 자막 오탈자와 신버전 수정 철자를 별개의 `small_ui` 정확 원문 후보로 모두 보존. 내부 룰 `id`는 고유하게 부여.
- `tools/build_supported_mods.py`: 두 호환 프로필은 *별도 모드 지원으로 집계하지 않고* 원래 모드의 번역 보조 파일로만 묶음.
- `tools/check_upgrade_compatibility.py`: 앞으로 구/신 영어 원문 쌍이 동시에 남았는지 자동 검사.
- `note/README.md`, `note/update.md`: **소스 ZIP과 설치용 배포 ZIP의 차이**를 명시하여 덮어쓰기 안내 대상 혼동 방지. ‘설치용 배포본은 덮어쓴다’는 기존 정책은 유지.

`docs/TRANSLATION_FORMAT.md`의 모드별 단일 프로필 원칙에서 한시적으로 벗어나는 이유: **소스 변경·DLL 재컴파일 없이 원문별로 다른 과거 한국어 번역을 보존할 방법이 필요**하기 때문. 일반 신규 모드/채널에서 임의 복제할 패턴은 아님.

## 검증 단계

- **실행 결과:** 원본 1.0.3의 활성 locale 20,391행을 수정본의 모든 후보와 `(키, 정확한 영어 원문)` 기준으로 대조하여 **매칭 누락 0건** 확인. 기존 한국어 본문까지 완전히 보존된 행 20,379건. 같은 영어를 유지하되 화자별 대사 교정으로 한국어만 변경한 12건은 구문 자체가 달라 동일 번역으로 집계하지 않음. Aishi 152건, Special Forces 6건의 과거 한글 문구는 모두 정확히 보존됨.
- 정적 검증 대상: 기존 번역 전체 키 삭제 여부, 구/신 양쪽 원문과 한국어, 동일 `(키,원문)` 번역 충돌, old/new 자막 원문 보존, 지원 목록 166개 집계, JSON/워크플로·계약 검사.
- C# 컴파일/최종 1.0.4 정식 배포 ZIP 생성/인게임 `kr`·`kr-en` 결과: **미실시 및 미확인**.
- 이 자료 전용 덮어쓰기 패치는 기존에 **정상 설치되어 실행 가능한 DLL을 가진 사용자**에게만 적용 가능. 새 빌드 DLL이 필요한 정식 1.0.4 설치본으로 오인하면 안 됨.

## 기타 제약

실제 인게임 영어 원문이 원본 모드 ZIP의 영어 외의 값으로 변경되는 상황까지 해결했다고 볼 수 없음. 사용자 인게임 사례 또는 서버 로케일 자료가 확보되면 `tools/audit_runtime_coverage.py`로 추가 대조 필요. 프로젝트의 다른 훅·모드 및 `docs/patches`는 수정하지 않음.
