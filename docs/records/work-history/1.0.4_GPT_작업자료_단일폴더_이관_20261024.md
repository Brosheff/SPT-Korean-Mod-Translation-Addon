# 1.0.4 GPT 작업 자료 보관 경로 통합 — 2026-10-24

- 사용자 요구: GPT 전용 작업 기록·참고 자료·검증 도구를 전부 `docs/` 아래에 두고 다른 프로젝트 경로에 기록 사본을 남기지 않음
- 경로 이관: `records/` → `docs/records/`, `reference-data/` → `docs/reference-data/`, `tools/` → `docs/tools/`
- 실행 코드 및 번역 데이터 내용은 유지. 작업 자료 이관과 검증 도구의 경로 계산, 빌드 도구 호출, 매뉴얼 링크를 함께 수정
- 기록은 현행 지침이 아닌 이력이며 재검사 결과는 별도 작업 결과에서 구분

## 실행한 검사 결과

- `python docs/tools/verify_workflow.py documents`: 통과.
- `python docs/tools/verify_workflow.py source`: 통과.
- `python docs/tools/validate_translations.py`: 113개 번역 프로필 통과.
- `python docs/tools/verify_quartermaster_contracts.py`: 통과.
- `python docs/tools/build_supported_mods.py`: 지원 목록 재생성 후 기존 내용과 동일.
- 모의 덮어쓰기 이관: 기존 루트 `records/`, `reference-data/`, `tools/`가 보존 이관되어 제거됨. 이관 후 source·documents 검사 통과.
- 부정 시험: 잘못된 루트 CSV 기록은 검사 실패, `docs/records/` 하위 기록은 허용.
- 주요 감사 도구 5개의 `--report`/출력 인자를 `docs/records/` 하위로 제한하는 경로 가드 도입. 외부 경로는 기록 전 거부.
- 원본 대비 번역·F12·C#·사용자 공개 `note` 등 핵심 파일 285개 바이트 동일. 원본의 기록 45개는 바이트 보존 이관. 참고 파일 2개 중 README만 현재 정책에 맞게 개정.
- Python 도구 15개 모두 구문 검사 통과. 빌드 스크립트에서 이동한 도구 4종 및 NuGet 설정 경로 확인.
- DLL 빌드 및 실제 SPT 게임 실행은 수행하지 않았으므로 결과 미확인.

## 다음 작업자를 위한 지시

- GPT가 생성하는 **모든 작업 기록·수정 이력·검증 결과·참고 자료 및 도구**는 `docs/` 아래 지정된 폴더에서만 관리합니다.
- 사용자 공개 `note/`는 예외적으로 기존 위치에 남지만 GPT 작업 결과를 기록하지 않습니다.
- 오래된 소스에 덮어쓰기 적용 후에는 `python docs/tools/migrate_docs_records.py`로 먼저 이관합니다.
