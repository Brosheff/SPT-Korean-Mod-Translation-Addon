# Manimal Terminal 0.2.2 영문 퀘스트 표시 재감사 — 2026-10-25

## 출발점과 판정 범위

사용자 실게임 화면에는 `Falling Skies - Part 1`의 제목과 설명이 영어로 표시된다. 그러므로 해당 키의 인게임 번역 실패는 확정이고, 이전의 데이터/빌드 검사 통과는 표시 성공의 근거가 아니다.

대조 원본: `SPT-Korean-Mod-Translation-Addon-v1.0.4-ManimalTerminal-Quality-Reviewed-Source (1).zip`, `...ManimalTerminal-Build-Independent-Merged-Source.zip`, `...Manimal-Compile-And-Regression-Fix-Source.zip`, 사용자 제공 `ManimalTerminal-master.zip`의 `terminal-server` 원본.

## 3가지 관점 및 반론

1. **파일 통합/데이터 보존:** 위 세 애드온 ZIP에서 `translations/Manimal Terminal.json`, `src/ClientLocaleModOverlay.cs`, `src/AddonBridge.cs`의 내용은 동일했다. 따라서 통합에서 이 파일들이 변경되어 번역이 지워졌다는 주장은 근거가 없다. 이미 존재한 적용 누락을 발견하지 못한 것은 별개 문제다.
2. **원본 언어 공급 경로:** Manimal 원본 `db/CustomQuests/prapor/Locales/en.json`의 101개 항목과 `db/CustomAchievements/Locales/en.json` 2개는 기존 번역 프로필의 같은 키/source와 전부 정확히 일치한다. 이 원본 디렉터리에 `kr.json`은 없다. `CustomDialogues/TheTicketLightkeeperDialogue.json`에는 별도 `localization.en`이 있어 글로벌 퀘스트 언어 경로와 동일하게 취급하면 안 된다.
3. **애드온 실행 연결:** 이전 `ClientLocaleModOverlay.Apply`는 `raw.TryGetValue(key)`가 실패하면 `locale` 번역을 무조건 건너뛰었다. 한국어 요청에서 영어 전용 서버 키가 누락된 경우에 번역이 적용될 기회가 없다는 논리적 결함이다.
4. **반론 및 대안:** 실제 서버가 한국어 raw에도 해당 키를 전달했다면 기존 정확 일치 경로가 적용될 수 있다. 따라서 관찰된 실패의 유일한 원인이 `raw` 키 누락이라는 증거는 없다. 이전 설치 DLL·프로필 누락·클라이언트 합성 로케일 호출 타이밍 등도 가능하다. 전역 exact 검사 삭제나 모든 UI 문자열의 일괄 치환은 기존 번역을 해칠 위험이 크므로 배제한다.

## 수정 내용과 안전 조건

- `src/TextRules.cs`: 개별 `locale` 규칙의 명시적 `seed_missing` 속성(기본 false).
- `src/ClientLocaleModOverlay.cs`: 서버 한국어 raw에 해당 키가 없고 **해당 규칙만** `seed_missing=true`일 때, 이미 존재하는 다른 한국어 값은 유지하면서 결과의 영어 원문/미존재 키만 로케일 결과에 안전하게 보충한다. 기존에 raw가 있는 행의 적용 로직은 유지한다. `LocaleDisplayRules.Select`의 퀘스트 제목·설명·목표의 자동 표기 방식도 유지한다.
- `translations/Manimal Terminal.json`: 원본 영어 전용 글로벌 로케일 103개(퀘스트 101, 업적 2)에만 속성을 설정. 다른 68개 로케일 및 나머지 113개 모드 번역 프로필은 기존 동작 유지.
- `build/validate_translations.py`: 잘못된 값/비exact 대상에서 누락 키 보충 플래그 사용 시 오류 검출.
- `docs/tools/check_manimal_english_only_locale.py`: 103개 × 한국어 2개 문화 × 7개 조건의 **모의** 회귀 검사(실제 C# 호출이나 인게임 시험은 아님).
- `docs/TRANSLATION_FORMAT.md`, `docs/번역작업안내서.md`: 명시적 옵트인 조건과 한계 기록.
