- 사용자 요청: GPT 작업 관련 모든 문서·도구·기록은 `docs/` 내부에 위치.
- `AGENTS.md`를 프로젝트 최상위에서 `docs/AGENTS.md`로 이동, 다른 파일 사본은 유지하지 않음.
- 현행 매뉴얼과 검증 도구에서 진입점 경로 및 상대 링크 변경.
