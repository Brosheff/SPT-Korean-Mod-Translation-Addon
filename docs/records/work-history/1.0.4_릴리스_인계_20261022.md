## 실행한 검사와 상태

- `python tools/build_supported_mods.py`: 누락 GUID 매핑 추가 후 통과. 166개 지원 항목(일반 113개, F12만 53개), F12 프로필 115개 인식.
- `python tools/verify_workflow.py source`: 통과.
- `python tools/validate_translations.py`: 통과. 프로필 113개.
- `python tools/verify_quartermaster_contracts.py`: 통과.
- `python tools/verify_workflow.py documents`: 통과.
- 버전 관련 클라이언트·서버 코드, 프로젝트 XML, 세 모드 `mod_version` 및 공개 문서 표기 일치: 별도 정적 검사 통과.
- 클라이언트 net48·서버 net10.0 **DLL 실제 컴파일 미실시**: 현재 실행 환경에 `dotnet` SDK가 없고 설치 서버에 네트워크 접근할 수 없어 빌드할 수 없음. 프로젝트의 컴파일 참조 DLL은 존재함.
- **설치용 1.0.4 배포 ZIP 생성·검사 미실시**: 해당 버전의 새로운 양쪽 DLL이 없으므로 구버전 DLL을 재사용한 완성 배포본을 제작하지 않음.
- **인게임 번역/언어 전환 표시 미확인**: SPT 4.1.6 실행·클라이언트 게임·서버 로그 제공 없음.

## 실제 배포를 마치려면

Windows 환경에서 프로젝트 폴더에 포함된 `BUILD_DISTRIBUTION.cmd`를 실행해 1.0.4 클라이언트·서버 DLL을 **각각 컴파일**해야 함. 이후 `_dist/SPT-Korean-Mod-Translation-Addon-SPT4.1.6-1.0.4.zip` 형태의 설치 파일이 실제 생성되고 `verify_workflow.py distribution` 검사에 통과하는지 확인해야 함. 빌드 성공만으로 인게임 검증을 대체하지 말 것.
