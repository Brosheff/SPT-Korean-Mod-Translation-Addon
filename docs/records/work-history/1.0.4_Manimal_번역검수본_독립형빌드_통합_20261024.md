# 1.0.4 번역 검수본 → 빌드 독립형 구조 통합 (2026-10-24)

## 입력과 적용 우선순위

- 기준 구조: `SPT-Korean-Mod-Translation-Addon-v1.0.4-Build-Independent-Source.zip`.
- 기능 변경 원본: `SPT-Korean-Mod-Translation-Addon-v1.0.4-ManimalTerminal-Quality-Reviewed-Source (1).zip`.
- 실행/빌드·GPT 자료 경로는 구조 기준을 유지하고, 번역과 개별 C# 훅 및 모드별 변경은 검수본에서 반영했다.
- 애드온 버전 1.0.4 고정; 원본 모드와 기존 번역 다른 프로필은 변경하지 않았다.

## 실제 반영

- 신규: `translations/Manimal Terminal.json` 및 `config-ui/com.manimal.terminal.json` (`mod_version: 0.2.2`).
- 신규: `src/ManimalTerminalUiHooks.cs`; 기존 `src/SmallUiLiteralHooks.cs`에서 클라이언트 어셈블리 시작/지연 로딩/Disable 연결.
- `src/DisplayHooks.cs`에 Manimal Terminal 및 Make Shotguns Great Again! 알림 GUID → 전용 번역 프로필 매핑 추가. 나머지 GUID와 기존 알림 경로 보존.
- Incendiary Grenade 1.1.0 일반 번역/F12 버전 정보 및 Make Shotguns Great Again! 1.19.0 일반 번역·F12 업데이트를 검수본 그대로 반영.
- `build/build_supported_mods.py`의 Manimal Terminal F12 GUID 매핑 추가, 지원 목록 `note/번역지원모드목록.md` 재생성(167개 지원 항목).
- 공개 `note/update.md`에는 검수본의 세 모드 추가/개선 사항을 반영하되 중간 작업 오류·감사 상태를 적지 않는다.
- `docs/records/versioning/` 대장·근거 CSV에 해당 3개 모드 6개 프로필 기록 반영(전체 230개 프로필). 개별 모드 작업 인계 3건은 `docs/records/work-history/`에 보존.

## 구조 불변 조건

- `BUILD_DISTRIBUTION.cmd`·`.ps1`, `build/`의 필수 검증 도구·컴파일 흐름은 독립형 기준과 바이트 동일.
- 프로젝트 루트에 과거 `AGENTS.md`, `tools/`, 별도 `records/`·`reference-data/`를 추가하지 않았다.
- GPT 문서 및 선택 감사 도구는 `docs/`에만 있으며 `docs/` 부재가 빌드 필수 검사 실패를 일으키지 않는다.
- 기존 `docs/records/patches/` 자료는 변경하지 않았다.

## 검증 범위

- 사용자 제공 검수본의 번역 3개·F12 3개·Manimal 새 훅 파일은 바이트 동일. `SmallUiLiteralHooks.cs`의 C# 본문은 줄바꿈을 제외하고 동일; `DisplayHooks.cs`의 두 신규 GUID 매핑도 동일.
- 구조 기준의 기존 369개 파일 중 바뀐 기존 파일은 11개. 원본 번역 프로필·C# 소스·도구에서 변경 허용 목록 밖의 기존 파일은 바이트 동일.
- `python build/verify_release.py source`: 통과.
- `python build/validate_translations.py`: 번역 JSON 114개 검사 통과.
- `python build/verify_quartermaster_contracts.py`: 통과.
- `python build/build_supported_mods.py`: 지원 목록 167개 생성.
- `python docs/tools/verify_workflow.py documents`: 통과.
- `python docs/tools/test_build_independence.py`: 7종 통과 (docs 미존재, 과거 Upload, 실제 번역/F12 오류 검출, 배포 ZIP 오류 검출 포함).
