# 1.0.4 최신 모드 버전 전용 구성 변경 기록

## 사용자 지시
- 과거 버전 전용 호환 번역 프로필과 검사용 스크립트를 제거한다.
- 지원 대상: Aishi 2.0.4, Special Forces 2.0.1, COTI 3.4.1.
- `docs/patches`는 변경하지 않는다.

## 실제 삭제
- `translations/ISB Aishi - 2.0.3 Compatibility.json` (152행, 과거 원문 후보 포함)
- `translations/ISB Special Forces - 2.0.0 Compatibility.json` (6행)
- `tools/check_upgrade_compatibility.py` (과거 영어 원문 검사 스크립트)

## 변경
- `tools/build_supported_mods.py`: `.legacy203`/`.legacy200` 별칭 집계 예외 제거. 현행 단일 프로필로 목록 생성.
- `translations/ISB Special Forces.json`: `.legacy`라고 명명한 자막 ID를 `.cue`로 변경. 이는 2.0.1 원본 **cues.json**의 오탈자 포함 영어 문자열이며, 같은 버전 `locales/en.json`의 정상 철자 영어 문자열도 존재한다. 둘 다 최신 버전 데이터이므로 같은 현재 번역 프로필에 유지한다.
- `translations/ISB Aishi.json`: 실제 Aishi 2.0.4 상인 등록 코드가 `kr`에 주입하는 `FullName`, `FirstName`, `Description` 원문을 기본 프로필에서 유지한다. `en.json`의 다른 3개 원문은 별도 구형 호환 파일에만 존재했던 후보이므로 이번 파일 삭제와 함께 제거된다. 두 공급 경로의 차이에 따른 실게임 출력은 여전히 미검증이다.
- `docs/TRANSLATION_FORMAT.md`: 이전 버전 호환 예외 삭제. 지난 회귀 보고는 역사 기록임을 명시.
- `note/README.md`, `note/update.md`: 과거 패치를 설치한 환경에서는 덮어쓰기만으로 구형 프로필 파일이 사라지지 않음을 명시.

## 완료 판정 제한
- 최신 버전 전용 번역 JSON / 도구 구성에 대한 정적 검사는 별도 결과를 기록한다.
- DLL 빌드 및 실제 게임의 한국어 출력은 수행한 경우에만 완료로 보고한다.
- 기존 구버전 원문이 삭제된 것은 사용자 요청에 따른 의도된 지원 종료이므로 1.0.3 구버전 원문 100% 보존을 합격 조건으로 사용하지 않는다.
