# 번역 원본 모드 버전 관리 대장 (1.0.4)

**자료:** 사용자 제공 `MOD SOUCES.zip` 내 원본 모드 ZIP 183개, 해당 버전의 메인 C# 프로젝트/패키지 메타데이터, 1.0.4 번역 프로필 및 기존 작업 주석.

**기록 정의:** JSON의 `mod_version`은 해당 번역 프로필을 검토할 때 참고할 **확보된 모드 원본/작업 기록의 버전**이며, 과거 최초 번역 당시 사용된 버전 또는 실제 게임에서 검증된 호환 버전을 증명하지는 않습니다. 이를 원본 코드 연결과 실행 검증의 대체로 사용하지 않습니다.

`target_spt: 4.1.6`과 `4.1-dev`, `spt-4.1` 브랜치는 모드 릴리스 버전과 분리했습니다. 외부 저장소/Git 이력은 검증하지 않았습니다. 프로젝트/파일명 버전 불일치는 각 행의 근거에 기록합니다.

원본 ZIP 메타데이터는 모드 버전 판정 근거이며 동일 ZIP을 과거에 실제 번역했는지까지 확증하는 정보는 아닙니다. 이력 확인이 필요한 항목은 별도로 재검토해야 합니다.

> **버전 근거 구분 (2026-10-23 보완):** 이전 미확인 26개는 `sp-mod.com`에 게시된 최신 모드 버전을 기록한 것입니다. 해당 버전이 제공된 과거 소스 ZIP 또는 최초 번역 당시 사용된 정확한 버전임을 증명하지 않습니다. 버전 필드는 현행 버전 조회 정보일 뿐, 번역 호환성 검사/인게임 검증 통과를 뜻하지 않습니다. 원본 소스와 실제 출력 경로를 검증하지 않은 채 완료 처리하지 않습니다. SPT 4.1.x 호환 버전은 모드 버전으로 대체하지 않습니다. 웹 원본 URL·확인일은 근거 CSV에 기록했습니다.

원본 ZIP별 SHA-256은 동봉된 `번역_원본모드_버전_근거목록_20261023.csv`에 기록했습니다. 각 해시는 `MOD SOUCES.zip` 내부 개별 ZIP 파일의 원본 바이트 기준입니다.

**현황(2026-10-23):** 일반 번역 113/113개, F12 115/115개 버전 필드 기록. 이전 미확인 26개는 Forge 공식 사이트의 **조회 시점 최신 버전**으로 보완했습니다. 기존 202개는 종전의 원본 소스/작업 기록 기준을 유지했습니다.

**2026-10-24 현재 1.0.4 유지 보완:** Incendiary Grenade와 Make Shotguns Great Again!의 일반 번역/F12 네 프로필은 이번에 제공된 소스·배포 ZIP을 기준으로 갱신했습니다. `1.1.0`은 Incendiary의 프로젝트 및 플러그인 선언에서, `1.19.0`은 Shotguns 동봉 DLL의 파일/제품 버전 리소스에서 확인했습니다. 정적 원문 대조에 한정하며 실제 게임 호환·표시 결과는 미확인입니다. 개별 SHA-256과 이전 버전값은 근거 CSV에 기록했습니다.

## 검사 및 유의사항

- 기존 번역 `channels`와 F12 `categories`, `entries`, GUID, mod_id 및 실제 화면 문자열은 전혀 수정하지 않았습니다. 새 필드는 기록용이며 기존 로더는 사용하지 않습니다.
- 현재 기록되지 않은 프로필은 원본 릴리스 버전 확인이 부족하며, 추측한 숫자는 입력하지 않았습니다.
- 더 높은 숫자라는 이유만으로 SPT 호환 버전·서브모듈/테스트 어셈블리 버전을 모드 버전으로 취급하지 않았습니다.
- `com.wtt.armory`는 `WTT-Armory-4.1-dev.zip`의 `4.1-dev`를 SPT 대상 브랜치로 보고 메인 프로젝트 `2.0.5`를 기록했습니다.
- `7Bpencil.WeaponCamoAndStickers`는 기존 F12 주석에 원본 코드 감사 버전 `1.19.0`이 명시되어 있어 제공된 별도 원본 ZIP `1.9.2`보다 이 기록을 우선했습니다. 실제 런타임 호환성은 별개입니다.
- 파일명과 모드 메인 프로젝트 버전이 충돌하는 경우 ZIP 배포 이름을 우선했으며, 근거를 기록했습니다. 내부 `AssemblyVersion=1.7.0` 같은 범용 기본값은 모드 릴리스 버전으로 사용하지 않았습니다.
- 동적 프로젝트 버전/번역 기준은 앞으로 최신 원본 자료·코드 및 실제 출력 경로와 별도 대조해야 합니다.
